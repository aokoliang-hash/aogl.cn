Runway

Video

Note: Bookmark-style intro on aogl.cn — not the vendor’s official docs. Features and pricing are on their site.

Runway is the video tab I open for short motion tests after still sheets exist—see role-girl MP4 passes and window composites like sky-plane. Not a replacement for screen recordings I already export as MP4 from the editor.

When I use it

  • 3–5 second identity checks on costumes that looked fine as PNGs.
  • Experimental b-roll I keep local if flicker is too high for articles.

When I skip it

  • Final publishes that need frame-accurate walk cycles — those stay PNG + canvas demos.
  • Any clip that would require upscale to hide artifacts on GitHub Pages bandwidth.

Steps

  1. Confirm plan and usage policy on Runway’s site (checked 2026-06-18).
  2. Import only assets I own or generated for practice folders.
  3. Export H.264; add poster frame before embedding like other articles.
