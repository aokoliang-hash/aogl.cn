Positioning: one library across modalities

Most “prompt dump” sites are either English-only Midjourney galleries or Chinese chat snippets glued into blogs. Prompt Share starts from a different contract: one catalog keyed by output modality and generation task, with bilingual prompt bodies as first-class fields. The homepage tagline states it plainly—多任务提示词库 · 中英双语 · 文图视频一站收藏. Navigation is short: 提示词, 合集, 提交, 管理 (admin login). That keeps the product a library + submission queue, not a social feed.

Running on a sibling origin (prompt.aogl.cn) next to the editorial site mirrors WordPet, EatToday, and Worlds Greatest: interactive product on its host; production notes and SEO on aogl.cn with first-paint HTML.

Filters that match how people actually generate

Two chip rows sit under search:

  • Output type — 全部, 文本, 图像, 视频, 音频 (?output_type=).
  • Task type — 文→文 (t2t), 文→图 (t2i), 图→图 (i2i), 多图→图 (r2i), 文→视频 (t2v), 图→视频 (i2v), plus overflow tasks: 多参→视频, 视频→视频, 文→音频, 语音→文, 图→文, 混合. A 精选 chip surfaces featured items.

Search placeholder copy—“搜索标题、摘要或提示词…”—indexes titles, summaries, and prompt bodies together. Collections are separate packs (homepage pill 「精选起步」 → /collection/getting-started; full index at /collections). Seed sample titles on the home grid include 城市夜景航拍运镜, 电影感人像光影, 品牌文案助手, 静物转微距运镜, 多参考服装平铺, and 产品图风格统一—covering video camera moves, portrait lighting, copywriting, and ecommerce image workflows.

Detail drawer: copy ZH, copy EN, keep parameters

Clicking a card opens a right-hand drawer (Midjourney-style, not a full page jump). For the night aerial sample, the drawer shows task 「文→视频」, model note 「可灵」, a one-line summary, then:

  • 中文提示词 with 复制 — e.g. 城市夜景航拍，霓虹倒影，缓慢向前推进，电影级稳定运镜，细雨湿路面。
  • English prompt with Copy — Aerial night cityscape, neon reflections, slow forward push-in, cinematic stabilized camera, wet streets after rain.
  • Optional negative prompt block when present.
  • Pills/tags such as fps 24, camera slow push-in, resolution 1080p, duration_sec 5, 可灵, 电影感.

A 「完整页」 link opens the full prompt page when you need a shareable URL. The drawer is the product’s core loop: browse → inspect bilingual text → copy → paste into Kling / Midjourney / GPT-class tools. Parameters live as structured pills so “24 fps / 5s / slow push-in” does not get lost in a paragraph.

Collections: curated packs, not endless scroll

/collections is titled 合集 with subtitle 专题打包的提示词精选. The first pack, 「精选起步」, is labeled 双语样例合集—explicitly a bilingual starter set. Packs matter for onboarding: new visitors should not face a raw filter wall with zero guidance. Editorial packs also give AdSense reviewers a human-curated path instead of an empty grid.

Submit without signup, publish after review

/submit states: 无需注册。提交后进入审核，通过后才会公开显示. The form captures:

  1. Task type (t2t…mixed), required title, optional English title, summary, model/tool (placeholder examples GPT-4o、Midjourney、可灵).
  2. Category (写作 / 图像 / 视频 / 工具), default display language, optional contact for admins only.
  3. Tags (max 8): GPT, Midjourney, 人像, 可灵, 电商, 电影感, etc.
  4. 中文提示词 + English prompt (at least one required), optional system prompts, optional negatives, Markdown notes, optional parameters JSON, license note, cover and result media uploads.
  5. 提交审核 — rate-limited; public only after admin approval.

That tradeoff is intentional: zero signup friction for contributors, but no spam flood on the homepage. A honeypot-style 公司网址 field exists for bots. Admin sits behind /admin/login.
