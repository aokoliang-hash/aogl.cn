About this site

aogl.cn is a personal bookmark for generative AI: official blog posts and doc entry points in one place. External links open in a new tab; blurbs here are excerpts or short notes — not a commercial review lab. Pricing, regional rules, and terms always belong on each vendor’s own pages.

The “content pillars” below map to on-page RSS categories; the tools directory groups common product homepages by scenario so you do not have to dig through bookmarks. If a link breaks, a name changes, or you want something removed, open a GitHub Issue with the URL and reason — I will fix it when I can.

This is not a newsroom: longer essays may live elsewhere; lists and briefs try to show date and source so you can verify later.
