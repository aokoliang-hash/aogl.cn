About this site

关于本站

Same idea as up top: links out to labs and docs I bother to read, plus tool tiles sorted by chat / image / video / code / audio / search — nothing proprietary, just faster than digging through bookmarks.

Longer write-ups might appear later; for now this page is the shelf. When something reads like news or a ranking, I try to keep the date and source obvious — fewer headaches for everyone.

和上面说的差不多：外链为主，把我常看的实验室 / 文档入口堆在一起；下面工具格子按对话、图像、视频、代码、音频、搜索分了类，没黑科技，就是省得翻收藏夹。

长文以后有空再写；目前就当货架用。涉及「新闻」或榜单时尽量写清时间和出处，自己也省得将来对不上账。
