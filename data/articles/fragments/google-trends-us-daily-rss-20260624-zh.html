怎么用（SEO 与日常）

  • 订阅 RSS — 比手动刷 Trending 页更省时间；本站在 JSON 里保留新闻链接便于二次引用。
  • 点 Explore 链接 — 表格中趋势词链至 trends.google.com/trends/explore?geo=US&q=…，可看地区曲线与相关查询。
  • 对照 CSV 存档 — RSS 约 10 条/轮；Trending 导出可有数百条（见 6/22 文章）。大事件日用 CSV，日常脉冲用 RSS 即可。
  • 仅 US — 换 geo=GB、geo=JP 等需换 RSS URL。
  • 更新本站 — 运行 node tools/fetch-google-trends-rss.mjs → 编辑 JSON 日期若需 → npm run build-articles · npm run build-seo-locales。
