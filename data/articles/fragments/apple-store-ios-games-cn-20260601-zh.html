如何读 App Store 游戏榜（SEO 与选题）

  • 与 Today 编辑推荐区分 — Today 是人工策展故事线；带序号的 grid 榜更接近「当前热门下载/排行」快照。勿把编辑卡片标题当成排名。
  • 副标题 = 运营快照 — 「S43 赛季」「7 周年」「马年宝藏」等是商店营销文案，会随活动更换；存档 JSON 保留抓取时点。
  • App ID — 链到 apps.apple.com/cn/app/…/idXXXXXXXX；同名不同区服 ID 可能不同。
  • 与下方书签对照 — 游戏 Hub「全球平台前十」书签已对搜索引擎 noindex；本篇正文表格为可索引原创解读。
  • 更新流程 — 编辑 JSON → npm run build-articles && npm run build-hubs。
