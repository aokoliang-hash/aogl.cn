This page archives the official Google Trends US RSS feed (Daily Search Trends), snapshot 2026-06-24. Raw data: data/google-trends-us-rss-snapshot.json. It complements our Jun 22 CSV Trending archive: fewer rows, but each item ships with related news headlines and URLs so you can see why a query spiked.

The RSS feed matches the Trending web UI. Fields include the query, ht:approx_traffic bands (e.g. 5000+, 500+), pubDate, and Google-curated ht:news_item blocks. Traffic bands are relative ranges, not exact search counts. Subscribe in any reader (Feedly, Inoreader, NetNewsWire) with https://trends.google.com/trending/rss?geo=US.

How to use this archive

  • vs CSV export — RSS ~10 items per pull; CSV exports can list hundreds (see Jun 22 article).
  • US only — change geo= in the RSS URL for other markets.
  • Refresh — node tools/fetch-google-trends-rss.mjs then npm run build-articles.
