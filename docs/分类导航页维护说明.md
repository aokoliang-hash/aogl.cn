# 七个「分类 / 榜单」静态页 — 维护说明（中文）

本站 `portal.html`、`brands.html`、`shopping.html`、`life.html`、`social.html`、`tech.html`、`games.html` 共 **七页**由本地脚本从 JSON 生成，页面上只保留简短个人说明与外链；**技术细节、字段含义与更新方式写在本文件**，不写在公开 HTML 里。

## 一、文件与命令

| 路径 | 作用 |
|------|------|
| `data/hubs/*.json` | 每类一页的数据源（文案、链接列表、区块标题、底部搜索标签等） |
| `scripts/build-hub-pages.mjs` | 读取 `data/hubs/*.json`，写出 **`_multilang/`** 下七个 hub 页（多语母版，不直接写根目录）。 |
| `css/hub.css` | 分类页在 `style.css` 之外的版式补充 |
| `_multilang/*.html` | 多语母版：hub 由上一行脚本生成；**`index.html`** 在此目录维护（工具目录、分类、阅读、pill 等注入脚本均改此文件）。 |
| `scripts/build-seo-locale-pages.mjs` | 从 `_multilang/` 生成根目录 **简体单语**、`/zh/` **繁体**（OpenCC）、`/en/` 等单语页及 `sitemap.xml`。 |

在项目根目录执行：

```bash
npm run build-hubs
```

修改 JSON 后执行 **`npm run build-hubs`**，再执行 **`npm run build-site`**（或至少 `npm run build-seo-locales`），根目录与各语种子目录才会更新。

### 与首页「关键词标签」的关系（非 hub 生成物）

首页 `#pillars` 下的多语言 pill 行来自 **`data/index-pills.json`**，由 **`scripts/inject-index-pills.mjs`** 写入 **`_multilang/index.html`** 中 `<!-- INDEX_PILLS_AUTO_START -->` … `<!-- INDEX_PILLS_AUTO_END -->` 之间。修改后执行：

```bash
npm run build-index-pills
```

样式与 hub 内 pill 一致（`css/style.css` 中的 `.pill-row` / `.pill`、`a.pill`），点击均为新标签打开 Google 搜索。

## 二、每个 JSON 里常见字段

- **`slug` / `outFile` / `path`**：与生成文件名、规范 URL 对应，勿随意改名。
- **`titleEn` / `titleZh`、`descEn` / `descZh`**：写入 `<title>` 与 `<meta name="description">`，以及双语切换时的页面标题与摘要（根节点 `data-title-*`、`data-desc-*`）。
- **`h1En` / `h1Zh`**：正文主标题。
- **`updated`**：页内「Updated / 更新」日期字符串，按实际整理日改即可。
- **`editorialHtmlEn` / `editorialHtmlZh`**：标题下的一段 HTML（可用 `<p>`），可为空；为空时生成页不输出该段。
- **`rankTitle*`、`newsTitle*`、`moreTitle*`**：三个大区块的二级标题。
- **`rankLead*`、`newsLead*`、`moreLead*`**：各区块标题下的一行说明；**若英中文都留空，生成页会省略该行**，避免空白说明。
- **`top10`**：图标网格，每项含 `nameEn`、`nameZh`、`url`、`domain`（`domain` 用于拉取 favicon）。
- **`newsGroups`**：多列「资讯」块；每组有 `id`、`labelEn`、`labelZh`、`items`（每条 `titleEn`、`titleZh`、`url`、`date`）。
- **`more`**：页尾扩展链接列表，结构同 `top10` 的单项（无 `top10` 的序号样式）。
- **`searchTags`**：字符串数组，建议 **固定 10 条**（英文检索词）。生成页在导语 `editorial` 区块之后插入一排 pill，每条为指向 Google 搜索的链接；非中文界面用该数组。
- **`searchTagsZh`**：字符串数组，建议 **固定 10 条**（中文检索词）。**中文界面**用该数组；若不足 10 条，脚本会回退用 `searchTags` 补齐。

## 三、链接选取习惯（页内不重复写）

1. **只外链**：本站不抓取、不镜像第三方正文；列表里都是跳转到对方域名的 URL。
2. **尽量用「单篇」地址**：新闻室稿、IR 新闻稿、单条博客或补丁说明，避免只做频道首页——方便以后核对是否失效。
3. **失效处理**：链接 404 或改版时，在对应 JSON 里替换 URL 或整条记录，再执行 `npm run build-hubs`。
4. **`top10` 排序**：各页写死为**公开全球榜单口径**的参考顺序（见下「三（附）」），不是本站测评；与「个人随手序」已区分。

## 五、与首页的关系

首页侧重生成式 AI 工具与相关阅读；**科技**页更偏半导体与平台型硬件公司，与首页「大模型货架」刻意分开，避免混在一栏里不好找。首页底部与 hub 页导语下的 **10 个关键词 pill** 均为站方配置的检索词外链（Google），与榜单条目本身无自动关联，需分别维护 `data/index-pills.json` 与各 `data/hubs/*.json` 中的 `searchTags*`。

## 六、多语种 SEO（简体根目录 + `/zh/` 繁体 + `/en/` 等）

多语内容只在 **`_multilang/`** 维护；`npm run build-seo-locales` 会生成：

- **根目录** `index.html`、`portal.html` 等：**仅简体中文**（`lang-zh`，`canonical` 为 `https://aogl.cn/` 或对应根路径）。
- **`/zh/`** 目录：**繁体中文**（由简体 `lang-zh` 经 OpenCC `cn→tw` 转换，`hreflang="zh-Hant"`）。
- **`/en/`、`/ja/`…**：各语言单语页；`hreflang` 含 `zh-CN`（根）、`zh-Hant`（`/zh/`）、`x-default`（英文 URL）。

语言切换见 **`js/i18n.js`**（含 **`zht`** = 繁体路径 `/zh/`）。

**约定**：日常改首页内容请编辑 **`_multilang/index.html`**，改 hub 请改 JSON 后 `build-hubs`；勿在根目录手改简体成品（会被下次 SEO 脚本覆盖）。

发布前建议一次性执行（先 hub 与首页 pill，再 SEO）：

```bash
npm run build-site
```

单独补跑多语种页与站点地图：

```bash
npm run build-seo-locales
```
