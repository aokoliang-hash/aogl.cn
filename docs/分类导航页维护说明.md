# 六个「分类导航」静态页 — 维护说明（中文）

本站 `portal.html`、`brands.html`、`shopping.html`、`life.html`、`social.html`、`tech.html`、`games.html` 七页由本地脚本从 JSON 生成，页面上只保留简短个人说明与外链；**技术细节、字段含义与更新方式写在本文件**，不写在公开 HTML 里。

## 一、文件与命令

| 路径 | 作用 |
|------|------|
| `data/hubs/*.json` | 每类一页的数据源（文案、链接列表、区块标题等） |
| `scripts/build-hub-pages.mjs` | 读取上述 JSON，写出六个 `.html` |
| `css/hub.css` | 分类页在 `style.css` 之外的版式补充 |

在项目根目录执行：

```bash
npm run build-hubs
```

修改 JSON 后务必重新执行，否则线上仍是旧 HTML。

## 二、每个 JSON 里常见字段

- **`slug` / `outFile` / `path`**：与生成文件名、规范 URL 对应，勿随意改名。
- **`titleEn` / `titleZh`、`descEn` / `descZh`**：写入 `<title>` 与 `<meta name="description">`，以及双语切换时的页面标题与摘要（根节点 `data-title-*`、`data-desc-*`）。
- **`h1En` / `h1Zh`**：正文主标题。
- **`updated`**：页内「Updated / 更新」日期字符串，按实际整理日改即可。
- **`editorialHtmlEn` / `editorialHtmlZh`**：标题下的一段 HTML（可用 `<p>`），可为空；为空时生成页不输出该段。
- **`rankTitle*`、`newsTitle*`、`moreTitle*`**：三个大区块的二级标题。
- **`rankLead*`、`newsLead*`、`moreLead*`**：各区块标题下的一行说明；**若英中文都留空，生成页会省略该行**，避免空白说明。
- **`top10`**：图标网格，每项含 `nameEn`、`nameZh`、`url`、`domain`（`domain` 用于拉取 favicon）。
- **`newsGroups`**：多列「资讯」块；每组有 `id`、`labelEn`、`labelZh`、`items`（每条 `titleEn`、`titleZh`、`url`、`date`）。
- **`more`**：页尾扩展链接列表，结构同 `top10` 的单项（无 `top10` 的序号样式）。

## 三、链接选取习惯（页内不重复写）

1. **只外链**：本站不抓取、不镜像第三方正文；列表里都是跳转到对方域名的 URL。
2. **尽量用「单篇」地址**：新闻室稿、IR 新闻稿、单条博客或补丁说明，避免只做频道首页——方便以后核对是否失效。
3. **失效处理**：链接 404 或改版时，在对应 JSON 里替换 URL 或整条记录，再执行 `npm run build-hubs`。
4. **`top10` 排序**：各页写死为**公开全球榜单口径**的参考顺序（见下「三（附）」），不是本站测评；与「个人随手序」已区分。

## 三（附）、「全球前十」各自参考什么

| 页面 | 口径（维护时对照公开榜单微调） |
|------|--------------------------------|
| `portal` | Similarweb / Cloudflare Radar 等全球访问量常见前十。 |
| `brands` | Interbrand《Best Global Brands》品牌价值榜常见前十。 |
| `shopping` | Digital Commerce 360、Statista 等全球网络零售 / GMV 类榜单。 |
| `life` | Data.ai、Sensor Tower 等全球月活或下载类榜单中的跨国服务。 |
| `social` | Data.ai、We Are Social 等全球社交应用月活常见前十。 |
| `tech` | 公开市场上市值与产业链话语权常见排序（非荐股）。 |
| `games` | Newzoo、行业营收分析里常见的全球发行与商店梯队。 |

原中文门户、国内电商与生活应用等放在各页 **`more`** 区块。
