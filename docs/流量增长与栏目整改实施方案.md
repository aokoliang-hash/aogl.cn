## 1. 定位（一句话）

**aogl.cn = 生成式 AI 工具实践手记 + 可玩 Web/游戏 Demo + 全球数字生活官方入口策展**

购物、品牌、游戏等 Hub **不是**导购站或攻略站，而是：回访便利、内链支撑、站长视角短文建立信任。

---

## 2. 现状与根因

| 问题 | 表现 | 对策 |
|------|------|------|
| 身份模糊 | 首页写 AI 备忘，导航 9 栏平铺 | 导航分层：流量栏前置，次要 Hub 收入「更多」 |
| 薄内容包袱 | GSC 约 70% URL 未索引 | `hub-links` 保持 noindex；不扩模板页 |
| 原创太少 | 12 篇 vs 数千聚合页 | 每月 1～2 篇深度原创（**当前 15 篇**） |
| 泛词无望 | 月点击约 7 次 | 只做品牌词 + 技术/工具长尾 |
| 权重分散 | 9 个 Hub 同等曝光 | 游戏/科技常显；购物/品牌等折叠 |

技术基线（2026-06-12 已做）：canonical 对齐、hub-links noindex、sitemap 瘦身、AdSense 收紧。本文聚焦**栏目战略与日常运营**。

---

## 3. 栏目三层架构

### 第一层：拉流量（80% 精力）

| 栏目 | 路径 | 词类方向 | 频率 |
|------|------|----------|------|
| **原创 Demo 手记** | `articles/` | WebGL/Three.js、角色设定、AI 视觉工作流长尾 | 每月 1～2 篇 |
| **AI 工具攻略** | `tool-guides/` + `guides/index.html` | 工具名 + workflow/notes/bookmark | 每月 1 篇深度扩写 |
| **官方快讯** | `briefs/` | 工具名 + news、官方发布长尾 | 随官方发布，不批量灌水 |

### 第二层：留存 + 内链（20% 精力）

| 栏目 | 路径 | 作用 | 维护 |
|------|------|------|------|
| **游戏** | `games.html` | 官方 RSS、Steam/御三家公告 | 每周 `fetch-hub-news` |
| **科技** | `tech.html` | 半导体/平台叙事 | 同上 |
| **购物/品牌/生活/社交/工具/全球站点** | 各 Hub | 策展入口，非 SEO 主力 | 季度核对榜单 |

### 第三层：站内导航（不追排名）

| 栏目 | 路径 | 说明 |
|------|------|------|
| hub-links | `hub-links/` | **noindex,follow**，仅站内跳转 |
| portal | `portal.html` | 全球站点前十书签 |

## 4. 导航结构（已实施）

```
本站原创 | AI 工具 | 快讯 | 游戏 | 科技 | 更多 ▾
                                              ├ 全球站点
                                              ├ 品牌
                                              ├ 购物
                                              ├ 生活
                                              ├ 社交
                                              └ 工具
```

| 项 | 链接 | 说明 |
|----|------|------|
| 本站原创 | `articles/index.html` | 主内容入口 |
| AI 工具 | `index.html#tools-directory` | 首页工具目录锚点 |
| 快讯 | `briefs/index.html` | 官方 headline briefs |
| 游戏 / 科技 | `games.html` / `tech.html` | 常访 Hub |
| 更多 | `<details>` 折叠 | 其余 6 个 Hub |

**攻略索引**：`guides/index.html` — 聚合全部 `tool-guides/`，从 AI 工具区或页内链入，不占用主导航位。

实现：`scripts/site-nav.mjs` 统一生成各页导航；`css/style.css` 中 `.site-nav-more` 样式。

## 6. 内容模板

### 原创 Demo（articles）

1. 要解决的问题（约 100 字）  
2. 工具/素材列表（链官方）  
3. 过程（截图/录屏）  
4. 可交互 Demo  
5. 踩坑与限制  
6. 内链（tool-guides / briefs / 相关 articles）  
7. 英文版 ≥ 800 words  

### 工具攻略（tool-guides 扩写）

1. 个人使用场景（非商业评测）  
2. 官方入口 + 定价页（注明核对日期）  
3. 3～5 步工作流（截图）  
4. 与同类差异（个人视角）  
5. 不适用场景  

### Hub 交叉文（每月可选 1 篇）

从游戏/品牌/购物 Hub 官方新闻出发 → 做一个小型 AI 实验 → 发在 `articles/`。

## 8. 日常维护清单

### 每周（30～45 分钟）

| 任务 | 操作 |
|------|------|
| GSC 巡检 | 索引报错、新 URL 状态 |
| Hub 新闻 | `npm run fetch-hub-news`（或 `refresh-hub-news`） |
| 更新记录 | `_multilang/changelog.html` 写 1 条 |
| 死链抽查 | 随机 5 个 hub-links |

### 每月（2～3 小时）

| 任务 | 操作 |
|------|------|
| 原创 | 1～2 篇 articles 或深度 tool-guide |
| 构建部署 | `npm run build-site` → `scripts/deploy.ps1` |
| 内链 | 新文链 Hub + 旧文互链 |
| 站外 | 每篇至少 1 次合规分享 |

### 每季度（约 1 小时）

- 核对 Hub 前十名单（portal/brands/shopping/games）  
- 某一 Hub 导语加 1 段「本季编辑注」  
- PageSpeed 移动端抽测  
- GSC 查询词 → 优化 2～3 个页面 title/描述
