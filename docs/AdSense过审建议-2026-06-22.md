# AdSense 过审建议（2026-06-22）

> **背景**：aogl.cn 与 aqqlang.com 均被拒，原因 **低价值内容（Low value content）**。ads.txt 已授权，问题在整站内容结构，不在技术验证。  
> **本文状态**：Phase 1 已实施；**Phase 2 全面整改**见 [`AdSense全面整改-2026-06-22.md`](./AdSense全面整改-2026-06-22.md)。  
> **关联**：[`AdSense过审改动清单.md`](./AdSense过审改动清单.md)、[`AdSense英文抽测记录.md`](./AdSense英文抽测记录.md)、[`低价值内容与SEO优化实施方案.md`](./低价值内容与SEO优化实施方案.md)

---

## 1. 2026-06-22 诊断摘要

| 指标 | 数值 | 对 AdSense 的含义 |
|------|------|-------------------|
| 原创文章 `/articles/` | 15 篇 | ✅ 主内容样本 |
| sitemap 总 URL（改前） | ~1,032 | 薄页占比过高 |
| sitemap 中 `briefs/`（改前） | ~320（40×8 语） | ❌ 模板化标题 + 外链 |
| sitemap 中 `tool-guides/`（改前） | ~464（58×8 语） | ❌ 工具目录简介 |
| sitemap 中 `articles/`（改前） | ~128 | ✅ 仅约 12% |
| `hub-links/` | ~500+ × 8 语（已 noindex） | ⚠️ 仍可爬，稀释整站印象 |
| AdSense 脚本（改前） | 文章 + briefs + tool-guides + guides | ❌ 在薄页请求 adsbygoogle |

**结论**：Google 将站点判为「AI 工具书签 / 聚合站」，而非「以原创正文为主的发布站」。15 篇厚文不足以抵消 700+ 可索引薄页与 4000+ hub-links 内链图。

---

## 2. 本次改动目标

1. **缩小 sitemap 中薄页占比**：briefs、tool-guides 移出 sitemap 并 `noindex,follow`。  
2. **AdSense 仅出现在主内容 URL**：`/articles/`、`about.html`、`changelog.html`。  
3. **15 篇英文全部 ≥800 词**：补齐 3 篇偏短样本。  
4. **复审前等待 2～4 周**，不在改完当天点「申请审核」。

改后 sitemap 预期：**~240 URL 以内**（15 篇×8 语 + 索引 + 首页/Hub/about 等），原创文章占比 **>50%**。

## 3. 已实施的技术改动（2026-06-22）

| # | 动作 | 文件 |
|---|------|------|
| 1 | `isContentPrimaryPage()` 仅匹配 `/articles/`、`about.html`、`changelog.html` | `js/adsense.js` |
| 2 | briefs 页 `noindex,follow`，移除 `adsense.js` | `scripts/build-brief-pages.mjs` |
| 3 | tool-guides 页 `noindex,follow`，移除 `adsense.js` | `scripts/build-tool-guide-pages.mjs` |
| 4 | guides 索引保留 `index,follow`，移除 `adsense.js` | `scripts/build-guides-index.mjs` |
| 5 | sitemap 排除 `briefs/`、`tool-guides/`（与 hub-links 同理） | `scripts/build-seo-locale-pages.mjs` |
| 6 | 扩写 3 篇英文偏短文章至 800+ 词 | `data/articles/fragments/*-en.html` |
| 7 | changelog 记录本次整改 | `_multilang/changelog.html` |

**构建命令**（改源码后必跑）：

```bash
npm run build-brief-pages
npm run build-tool-guide-pages
npm run build-guides-index
npm run build-articles
npm run build-seo-locales
```

或：`npm run build-site`

| 项 | 说明 |
|----|------|
| **自动广告版位** | **不必**在 AdSense 后台按 URL 单独收窄。站点已在 `js/adsense.js` 里用 `isContentPrimaryPage()` 控制：**只有** `/articles/`、`about.html`、`changelog.html` 才会加载 `adsbygoogle.js`；首页、Hub、briefs、tool-guides 等页虽引用 `adsense.js` 文件，但**不会发起广告请求**。后台保持默认「自动广告」即可。 |
| 申请审核 | **不早于 2026-07-06**（距 2026-06-22 部署 ≥2 周） |
