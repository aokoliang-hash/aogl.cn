# 站外分享操作指引

> **版本**：2026-06-18  
> **用途**：每篇新原创或攻略扩写后的合规外推（对应 12 周路线第 9～10 周）  
> **原则**：带 canonical 回本站，不刷量、不买链

---

## 1. 分享前检查（每篇 5 分钟）

- [ ] 英文版段落完整、无「TODO」占位  
- [ ] 文内至少 2 条站内内链（articles / guides / briefs / hub）  
- [ ] `npm run build-site` 已通过  
- [ ] 选用 **英文 canonical URL**（`https://aogl.cn/en/articles/<slug>.html` 或 `/en/guides/...`）

---

## 2. 推荐渠道与话术模板

### GitHub README（仓库首页）

已在 `README.md` 维护 **Editorial demos** 表。新发文章后：

1. 在表中增加一行：标题 + `https://aogl.cn/en/articles/<slug>.html`  
2. commit 后即为一次「站外」曝光（开发者受众）

### Dev.to（转载英文节选）

1. 注册 [Dev.to](https://dev.to/)，Settings → 填写 website 为 `https://aogl.cn`。  
2. 新发文时 **Canonical URL** 填本站英文页。  
3. 正文：节选 600～900 词 + 「Full notes and demos:」链回本站。  
4. 标签示例：`webgl`、`threejs`、`ai`、`tutorial`（按文选 4 个）。  

**适合篇目**：`interactive-3d-earth`、`games-hub-generative-art-workflow`、工具攻略英文段。

### X（Twitter）/ 个人动态

单条模板（英文）：

```
New maintainer notes on aogl.cn: [标题] — [一句 hook，如 WebGL / character turnaround / tool workflow].
https://aogl.cn/en/articles/[slug].html
(not a review site; personal bookmarks + demos)
```

避免：堆砌 hashtag、@ 官方账号求转、同一 URL 24h 内重复发。

### 技术社区（可选）

| 社区 | 适用内容 | 注意 |
|------|----------|------|
| Hacker News (Show HN) | 可交互 WebGL Demo | 标题诚实写「personal project」，勿标题党 |
| Reddit r/webdev, r/threejs | 3D Earth、角色设定表 | 遵守各 sub 自荐规则，先发参与再发链接 |
| V2EX / 掘金（中文） | 艾琳娜线、构建脚本备忘 | 标明个人站，不抄全文 |

## 3. 12 周路线中的「2 次分享」示例（已完成内容）

| # | 篇目 | 建议渠道 | Canonical |
|---|------|----------|-----------|
| 1 | Games hub × generative art workflow | Dev.to 节选 + X | `/en/articles/games-hub-generative-art-workflow.html` |
| 2 | Elena palette & ritual UI | X + GitHub README 表项 | `/en/articles/game-girl-elena-palette-ritual-notes.html` |

工具攻略扩写（Copilot、Midjourney 等）可在 guides 索引更新后发 **一条** 汇总帖，链到 `https://aogl.cn/en/guides/index.html`。

---

## 4. 禁止事项

- 购买外链、互链农场、流量交换  
- 在无关论坛群发同一链接  
- 将 hub-links 薄页当作分享素材  
- 转载时不设 canonical（避免与本站抢排名）

---

## 5. 记录

在 `_multilang/changelog.html` 或私人笔记记录：**日期 · 篇目 · 渠道 · URL**，便于季度复盘 GSC 查询词变化。
