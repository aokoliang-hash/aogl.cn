# AdSense 全面整改方案（2026-06-22）

> **目标**：让 Google / AdSense 将 aogl.cn 识别为「**以原创文章为主**的个人站点」，而非 AI 书签聚合站。  
> **状态**：**代码已全部实施**（含 Phase 1 + Phase 2）。  
> **关联**：[`AdSense过审建议-2026-06-22.md`](./AdSense过审建议-2026-06-22.md)（Phase 1 摘要）

---

## 1. 为何 Phase 1 仍可能不过

| 残留问题 | 说明 |
|----------|------|
| sitemap 仍含 8 个 Hub + official-news + guides | ~80 URL，仍是 RSS/外链目录 |
| 首页 JSON-LD 含 24 条 brief-list | 向 Google 声明「新闻聚合」 |
| 首页 / Hub 仍 `index,follow` | 与 15 篇文章竞争「主内容」信号 |
| 首页 / Hub 仍引用 `adsense.js` | 虽 gated，但 HTML 仍像广告站 |
| 审核员打开 aogl.cn 首屏 | 下方仍是巨大工具格子 |

Phase 1（briefs/tool-guides noindex）把 sitemap 从 ~1032 收到 ~248，但**书签类 URL 仍占 ~32%**。Phase 2 进一步收到 **~168**，文章占比 **>75%**。

---

## 2. Phase 2 已实施改动

| # | 动作 | 文件 |
|---|------|------|
| 1 | 统一策略模块 `isNoindexPage` / `isSitemapPage` | `scripts/seo-index-policy.mjs` |
| 2 | sitemap **白名单**：仅 `articles/*` + index/about/changelog/privacy/contact | `scripts/build-seo-locale-pages.mjs` |
| 3 | 8 个 Hub 垂直页 + `official-news.html` → `noindex,follow`，移除 adsense | `scripts/build-hub-pages.mjs`、`build-official-news-page.mjs` |
| 4 | `guides/index.html` → `noindex,follow` | `scripts/build-guides-index.mjs` |
| 5 | 首页 JSON-LD **移除 brief-list**，WebSite 描述改为 editorial-first | `scripts/official-feeds-lib.mjs` |
| 6 | 首页移除 `adsense.js` 引用 | `_multilang/index.html` |
| 7 | 首页 `#originals` 增加第二段说明（书签页 noindex） | `scripts/build-articles.mjs` |
| 8 | About 页明确「articles 为唯一索引主内容」 | `_multilang/about.html` |

**仍保持 index,follow 的页面**（人类入口 + 信任页）：

- 首页各语言、`about`、`changelog`、`privacy`、`contact`
- 全部 `articles/*`

**全部 noindex 但仍可站内访问**：

- `hub-links/`、`briefs/`、`tool-guides/`
- `portal` … `tools` 八个 Hub、`official-news`、`guides/index`

---

## 3. AdSense 代码策略（不变）

`js/adsense.js` 仅在以下 URL **加载** `adsbygoogle.js`：

- `/articles/…`
- `about.html`
- `changelog.html`

**不必**改 AdSense 后台 URL 版位。
