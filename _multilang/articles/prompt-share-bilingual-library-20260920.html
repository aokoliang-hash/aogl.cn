Prompt Share — bilingual multi-task prompt library notes

Built by me · App: http://prompt.aogl.cn/ · text/image/video · collections · submit

2026-09-20 · aogl.cn original

This is a first-party build log on aogl.cn. Screenshots live under original/prompt-share/ (archived 2026-09-20). Prompt Share is an app I developed myself (footer © 2026 Prompt Share · 提示词分享). App link: http://prompt.aogl.cn/—a bilingual multi-task prompt library for text, image, video, and audio workflows. Cards open a Midjourney-style detail drawer with Chinese and English prompts you can copy; collections package starters; anyone can submit without registering, pending admin review. This page is not affiliate marketing. It walks through my own UI captures—home filters, drawer detail, submit form, collections index—so search engines and humans can index phrases like “bilingual AI prompt library,” “text to video prompt share,” “Chinese English Midjourney Kling prompts,” and “prompt.aogl.cn.”

What’s in the folder

  • rd.txt — product URL: http://prompt.aogl.cn/.
  • home.png — hero “Prompt Share”, search field, 全部/文本/图像/视频/音频, task chips, 精选起步, six prompt cards.
  • drawer-city-night-aerial.png — detail drawer for 「城市夜景航拍运镜」with ZH/EN copy blocks and parameter pills.
  • submit.png — /submit form: task type, bilingual titles, tags, ZH/EN prompt fields, 提交审核.
  • collections.png — /collections index with 「精选起步 · 双语样例合集」.
  • homepage-raw.html — HTML snapshot for provenance (encoding may vary by scrape).

Captures were taken in a browser at http://prompt.aogl.cn/. Prefer the http:// entry the product currently serves. Pairing structured prose with descriptive alt text beats a bare outbound link.

Positioning: one library across modalities

Most “prompt dump” sites are either English-only Midjourney galleries or Chinese chat snippets glued into blogs. Prompt Share starts from a different contract: one catalog keyed by output modality and generation task, with bilingual prompt bodies as first-class fields. The homepage tagline states it plainly—多任务提示词库 · 中英双语 · 文图视频一站收藏. Navigation is short: 提示词, 合集, 提交, 管理 (admin login). That keeps the product a library + submission queue, not a social feed.

Running on a sibling origin (prompt.aogl.cn) next to the editorial site mirrors WordPet, EatToday, and Worlds Greatest: interactive product on its host; production notes and SEO on aogl.cn with first-paint HTML.

Filters that match how people actually generate

Two chip rows sit under search:

  • Output type — 全部, 文本, 图像, 视频, 音频 (?output_type=).
  • Task type — 文→文 (t2t), 文→图 (t2i), 图→图 (i2i), 多图→图 (r2i), 文→视频 (t2v), 图→视频 (i2v), plus overflow tasks: 多参→视频, 视频→视频, 文→音频, 语音→文, 图→文, 混合. A 精选 chip surfaces featured items.

Search placeholder copy—“搜索标题、摘要或提示词…”—indexes titles, summaries, and prompt bodies together. Collections are separate packs (homepage pill 「精选起步」 → /collection/getting-started; full index at /collections). Seed sample titles on the home grid include 城市夜景航拍运镜, 电影感人像光影, 品牌文案助手, 静物转微距运镜, 多参考服装平铺, and 产品图风格统一—covering video camera moves, portrait lighting, copywriting, and ecommerce image workflows.

Detail drawer: copy ZH, copy EN, keep parameters

Clicking a card opens a right-hand drawer (Midjourney-style, not a full page jump). For the night aerial sample, the drawer shows task 「文→视频」, model note 「可灵」, a one-line summary, then:

  • 中文提示词 with 复制 — e.g. 城市夜景航拍，霓虹倒影，缓慢向前推进，电影级稳定运镜，细雨湿路面。
  • English prompt with Copy — Aerial night cityscape, neon reflections, slow forward push-in, cinematic stabilized camera, wet streets after rain.
  • Optional negative prompt block when present.
  • Pills/tags such as fps 24, camera slow push-in, resolution 1080p, duration_sec 5, 可灵, 电影感.

A 「完整页」 link opens the full prompt page when you need a shareable URL. The drawer is the product’s core loop: browse → inspect bilingual text → copy → paste into Kling / Midjourney / GPT-class tools. Parameters live as structured pills so “24 fps / 5s / slow push-in” does not get lost in a paragraph.

Collections: curated packs, not endless scroll

/collections is titled 合集 with subtitle 专题打包的提示词精选. The first pack, 「精选起步」, is labeled 双语样例合集—explicitly a bilingual starter set. Packs matter for onboarding: new visitors should not face a raw filter wall with zero guidance. Editorial packs also give AdSense reviewers a human-curated path instead of an empty grid.

Submit without signup, publish after review

/submit states: 无需注册。提交后进入审核，通过后才会公开显示. The form captures:

  1. Task type (t2t…mixed), required title, optional English title, summary, model/tool (placeholder examples GPT-4o、Midjourney、可灵).
  2. Category (写作 / 图像 / 视频 / 工具), default display language, optional contact for admins only.
  3. Tags (max 8): GPT, Midjourney, 人像, 可灵, 电商, 电影感, etc.
  4. 中文提示词 + English prompt (at least one required), optional system prompts, optional negatives, Markdown notes, optional parameters JSON, license note, cover and result media uploads.
  5. 提交审核 — rate-limited; public only after admin approval.

That tradeoff is intentional: zero signup friction for contributors, but no spam flood on the homepage. A honeypot-style 公司网址 field exists for bots. Admin sits behind /admin/login.

Why sibling host + editorial archive

Archiving timestamped screenshots into original/prompt-share/ preserves capture provenance. Hero generation goes through npm run generate-article-covers for Open Graph WebP. Chinese body copy serves “提示词库 / 文生视频 / 可灵提示词” intent; English serves “bilingual prompt library / text-to-video prompts / Kling Midjourney share.” Short locales stay brief—the thick bilingual pair carries AdSense weight.

Compared with ranking-table archives (noindex), Prompt Share belongs in the indexable primary bucket: original product, original screenshots, first-person notes—same class as WordPet and EatToday.

Workflow notes I refuse to water down

  1. Quote UI labels exactly: Prompt Share, 合集, 提交审核, 文→视频, 精选起步.
  2. Do not claim prompts are vendor-official; they are community/editorial recipes for tools like Kling and Midjourney.
  3. Prefer http://prompt.aogl.cn/ in live links until HTTPS is confirmed stable.
  4. Seed card counts change after each review cycle—this essay freezes the 2026-09-20 capture set.
  5. Submit is moderated; “no login” does not mean “instantly public.”

Accessibility and SEO checklist

  • Alt text names filters, drawer titles, and form sections—never “image 1.”
  • Body repeats Prompt Share, http://prompt.aogl.cn/, bilingual, t2i/t2v, 合集, 提交审核, 可灵, Midjourney.
  • Outbound product links use rel="noopener noreferrer"; narrative ships in first-paint HTML.

Boundaries

These screens document Prompt Share, an app I built—a personal product and UI archive. Prompt texts, tags, and pack membership change over time. Nothing here claims affiliation with OpenAI, Midjourney, or Kling. Users remain responsible for how they use generated media.

Prompt Share：中英双语多任务提示词库手记

本人开发 · App：http://prompt.aogl.cn/ · 文图视频 · 合集 · 提交审核

2026-09-20 · 本站原创

这是 aogl.cn 上的本人一手产品手记。截图归档在 original/prompt-share/（2026-09-20）。Prompt Share 是我自己开发的应用（页脚 © 2026 Prompt Share · 提示词分享）。入口：http://prompt.aogl.cn/——面向文本、图像、视频、音频工作流的中英双语多任务提示词库。卡片打开类似 Midjourney 的右侧抽屉，可一键复制中英文提示词；合集打包入门样例；任何人可无注册提交，经管理员审核后公开。本文不是联盟软文，而是对照本人 UI 截图写清：首页筛选、抽屉详情、提交表单、合集索引，方便检索「双语提示词库」「文生视频提示词分享」「可灵 / Midjourney 中英提示词」「prompt.aogl.cn」等意图。

文件夹里有什么

  • rd.txt — 产品地址：http://prompt.aogl.cn/。
  • home.png — 英雄区「Prompt Share」、搜索、全部/文本/图像/视频/音频、任务芯片、精选起步、六张提示词卡。
  • drawer-city-night-aerial.png — 「城市夜景航拍运镜」抽屉：中英提示词与参数胶囊。
  • submit.png — /submit 提交表：任务类型、双语标题、标签、中英提示词、提交审核。
  • collections.png — /collections 合集索引：「精选起步 · 双语样例合集」。
  • homepage-raw.html — 首页 HTML 快照（编码可能因抓取环境不同）。

截图均在浏览器打开 http://prompt.aogl.cn/ 时拍摄。产品当前以 http:// 入口为准。结构化正文 + 描述性 alt，比只丢一个外链更利于收录。

定位：跨模态的一座库

多数「提示词站」要么是纯英文 Midjourney 瀑布流，要么是中文聊天片段贴进博客。Prompt Share 的契约不同：按输出模态与生成任务建目录，中英提示词正文是一等公民字段。首页标语写得很直白——多任务提示词库 · 中英双语 · 文图视频一站收藏。导航很短：提示词、合集、提交、管理。产品是「库 + 投稿队列」，不是社交动态墙。

放在子域 prompt.aogl.cn，与 WordPet、EatToday、世界之最同一套路：交互产品在子域；制作手记与 SEO 长文留在 aogl.cn 首屏 HTML。

筛选：按人们真正生成的方式切

搜索框下方两行芯片：

  • 输出类型 — 全部、文本、图像、视频、音频（?output_type=）。
  • 任务类型 — 文→文 (t2t)、文→图 (t2i)、图→图 (i2i)、多图→图 (r2i)、文→视频 (t2v)、图→视频 (i2v)，以及「更多」里的多参→视频、视频→视频、文→音频、语音→文、图→文、混合；另有「精选」。

搜索占位「搜索标题、摘要或提示词…」把标题、摘要与提示词正文一并检索。合集是独立打包（首页「精选起步」→ /collection/getting-started；总览 /collections）。首页样例标题包括：城市夜景航拍运镜、电影感人像光影、品牌文案助手、静物转微距运镜、多参考服装平铺、产品图风格统一——覆盖运镜、人像光影、文案与电商出图。

详情抽屉：中英复制，参数不丢

点卡片打开右侧抽屉（类似 Midjourney，不必整页跳转）。夜景航拍样例可见任务「文→视频」、模型「可灵」、一行摘要，然后：

  • 中文提示词 + 复制 — 例如：城市夜景航拍，霓虹倒影，缓慢向前推进，电影级稳定运镜，细雨湿路面。
  • English prompt + Copy — Aerial night cityscape, neon reflections, slow forward push-in…
  • 若有负面提示则单独一块。
  • 胶囊/标签：fps 24、camera slow push-in、resolution 1080p、duration_sec 5、可灵、电影感等。

「完整页」用于需要可分享 URL 时打开独立页。核心循环是：浏览 → 看双语正文 → 复制 → 贴进可灵 / Midjourney / GPT 类工具。参数做成结构化胶囊，避免「24fps / 5 秒 / 缓推」淹没在长段落里。

合集：专题打包，而不是无限滚动

/collections 标题为「合集」，副标题「专题打包的提示词精选」。首个包「精选起步」标注「双语样例合集」。合集服务入门：新访客不该面对只有筛选、没有指引的空墙。对审核员而言，人工打包路径也比空洞网格更像「作者在策展」。

无注册提交，审核后公开

/submit 写明：无需注册。提交后进入审核，通过后才会公开显示。表单收集：

  1. 任务类型（t2t…mixed）、必填标题、可选英文标题、摘要、模型/工具（示例 GPT-4o、Midjourney、可灵）。
  2. 分类（写作 / 图像 / 视频 / 工具）、默认展示语言、仅管理员可见的联系方式。
  3. 标签最多 8 个：GPT、Midjourney、人像、可灵、电商、电影感等。
  4. 中文提示词 + English prompt（至少一侧）、可选系统提示与负面提示、Markdown 说明、参数 JSON、授权说明、封面与效果素材。
  5. 提交审核 — 有频率限制；前台仅展示已通过条目。

取舍很明确：投稿零注册摩擦，首页不被垃圾刷屏。表单含「公司网址」蜜罐字段；管理入口在 /admin/login。

为何子域 + 本站归档

时间戳截图放进 original/prompt-share/ 便于追溯。封面走 npm run generate-article-covers 生成 Open Graph WebP。中文服务「提示词库 / 文生视频 / 可灵提示词」；英文服务 bilingual prompt library / text-to-video / Kling Midjourney share。短语言包故意短——过审重量在中英厚文。

相对本站榜单存档（noindex），Prompt Share 属于可索引主文：原创产品、原创截图、第一人称过程，与 WordPet、EatToday 同类。

写作时不愿稀释的约束

  1. UI 文案照抄：Prompt Share、合集、提交审核、文→视频、精选起步。
  2. 不声称提示词为厂商官方；它们是面向可灵、Midjourney 等工具的社区/编辑配方。
  3. 外链优先写 http://prompt.aogl.cn/，直至 HTTPS 稳定。
  4. 卡片数量会随审核变化；本文冻结 2026-09-20 截图集。
  5. 「无需注册」≠「立刻公开」；必须过审。

无障碍与 SEO 清单

  • alt 写清筛选、抽屉标题与表单分区，禁止「图片 1」。
  • 正文重复：Prompt Share、http://prompt.aogl.cn/、双语、t2i/t2v、合集、提交审核、可灵、Midjourney。
  • 产品外链 rel="noopener noreferrer"；完整叙事在首屏 HTML。

边界

这些截图记录的是本人开发的 Prompt Share——个人产品与 UI 归档。提示词正文、标签与合集成员会随时间变化。本文不声称与 OpenAI、Midjourney 或可灵存在官方合作。生成内容如何使用，由使用者自行负责。
