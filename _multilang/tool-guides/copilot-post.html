Note: Bookmark-style intro on aogl.cn — not the vendor’s official docs. Features and pricing are on their site.

Microsoft Copilot is the chat entry I use when I am already in Edge or Windows and want a fast web-grounded answer without opening my full Claude session. Listed on the home tools directory; not a Microsoft endorsement.

When Copilot wins on aogl.cn maintenance

  • Summarizing a long Microsoft or GitHub doc page before I edit build scripts.
  • Quick “what changed in this Windows/Electron API” questions while testing locally on WAMP.
  • Drafting short changelog bullets I later hand-edit in git.

For repo-wide refactors I still use Cursor; for cited research Perplexity.

Five-step bookmark routine

  1. Open copilot.microsoft.com from the button below.
  2. Confirm whether the session is signed in with the Microsoft account I intend.
  3. Paste only non-secret snippets.
  4. Copy useful output into my own notes—never auto-publish to the site.
  5. Check pricing and region on Microsoft’s pages; this guide only records 2026-06-18.

Not for

  • Replacing investor filings or legal text.
  • Scraping paywalled game press for the games hub.

Related: GitHub Copilot · games hub workflow article.

Last checked: 2026-06-18.

说明：本页为 aogl.cn 书签站整理的工具简介，非厂商官方文档；功能与价格以官网为准。

Copilot 是我在 Edge / Windows 里想快速要一个带网页语境的答案时开的入口，不必先开完整 Claude 会话。见首页工具目录；非微软背书。

维护本站时何时用

  • 改构建脚本前先概括长篇微软 / GitHub 文档。
  • 本地 WAMP 测试时查 Windows / API 变更。
  • 起草 changelog 短句再进 git 手改。

全仓库重构用 Cursor；要引用来源用 Perplexity。

五步流程

  1. 从下方按钮进 copilot.microsoft.com。
  2. 确认登录的是预期微软账户。
  3. 只贴非机密片段。
  4. 有用结论抄进自己的笔记，不自动发站。
  5. 价格与地区以微软官网为准；本页核对 2026-06-18。

另见：GitHub Copilot · 游戏 Hub 工作流文。

核对日期：2026-06-18。
