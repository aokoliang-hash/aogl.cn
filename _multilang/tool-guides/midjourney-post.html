Note: Bookmark-style intro on aogl.cn — not the vendor’s official docs. Features and pricing are on their site.

Midjourney is my default text-to-image exploration tab when I need costume silhouettes and palette passes for character folders under original/. This bookmark page is not Midjourney documentation.

How it feeds aogl.cn articles

  • Early passes for role-girl and Elena lines (exploration PNGs, not final SKU art).
  • Mood frames I later reject—kept on disk with dated filenames for honest “discard log” prose.
  • Never used to mirror official game key art from the games hub.

Workflow

  1. Start from the official site link below.
  2. Lock aspect ratio early (character sheets often 2:3 or 16:9).
  3. Export to original/<project>/ with date in filename.
  4. Compare against identity anchors before swapping HTML sheet sources.
  5. Publish an article only when scope paragraph is honest—see workflow notes.

Limits

Discord/community rules and plan tiers change—verify on vendor site. I do not host MJ grids on aogl.cn; only finished notes and downscaled figures in articles.

说明：本页为 aogl.cn 书签站整理的工具简介，非厂商官方文档；功能与价格以官网为准。

Midjourney 是我做 original/ 角色文件夹时文生图探索的默认标签页。本页不是 Midjourney 官方文档。

如何进入本站文章

  • role-girl、艾琳娜 等线的早期探索 PNG（非最终 SKU）。
  • 淘汰帧也保留日期文件名，便于写「弃稿说明」。
  • 不用于镜像 游戏 Hub 上的官方 KV。

流程

  1. 从下方官网进入。
  2. 先锁定画幅（设定表常用 2:3 或 16:9）。
  3. 导出到 original/项目/ 并带日期。
  4. 对照身份锚点再换 HTML 源图。
  5. 只有范围段诚实时才发文章——见 工作流文。

对比：Gemini 出图 · 攻略索引。

核对日期：2026-06-18。
