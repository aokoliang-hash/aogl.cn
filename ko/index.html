이 사이트 소개

아래 「콘텐츠 구역」은 페이지 내 RSS 분류에 맞추었고, 「도구 디렉터리」는 대화·이미지·영상·코드 등 시나리오별로 자주 쓰는 공식 사이트를 모았습니다. 링크 오류·명칭 변경·삭제 요청은 GitHub Issue 에 URL과 이유를 적어 주세요. 시간이 나면 반영합니다.

이 사이트는뉴스룸이 아닙니다. 긴 글은 따로 쓰고, 목록·브리핑에는 날짜와 출처를 가능한 한 분명히 둡니다. 운영자 연락처는 문의 페이지를 참고하세요.
