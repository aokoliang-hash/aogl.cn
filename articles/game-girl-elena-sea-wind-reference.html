海岛祭司艾琳娜：海风之诗设定表与生成探索

elena_character_sheet.html · ChatGPT-Image2 三视图源 · 5/18–5/20 探索图

2026-06-03 · 本站原创

这是 aogl.cn 上的第 13 篇原创归档，素材全部来自 original/game-girl/。和 白裙 role-girl 卡牌线、girl1 米色针织线 并列：本篇走的是海岛幻想 + 祭司职业——中文名「艾琳娜」，称号「海风之诗」，22 岁、168 cm，所属「碧海群岛·潮音祭司团」。目标不是交付可上线的游戏角色包，而是把生成式出图收束成一张可读的设定表 HTML、一张三视图源图、若干日期命名的探索 PNG，并用这篇手记说明「留下什么、为什么」。这不是工具教程，也不教你去某个 App 里复制提示词。

我为什么选「祭司 + 沙滩纱裙」而不是再画一条现代都市线

本站已有城市窗边针织、白蕾丝卡牌、动画向四视图行走——再堆一条「普通 T 恤少女」只会和 girl1 抢识别度。海岛线的好处是轮廓与配色自带边界：象牙白抹胸、半透明纱裙、金链腰饰、潮沙法杖、栀子花环，在缩略图里仍然可读。我把世界观写成「碧海群岛」的轻幻想，不是硬科幻，这样我在 HTML 里写色板和世界设定段落时，不会和真实宗教符号搅在一起——页面里用的是虚构组织「潮音祭司团」与海洋女神信仰，明确标注为个人练习。

定稿前的最大风险是「每张都像泳装广告」。我在设定表里强制保留168 cm 身高标尺、三视图裁切框、五枚表情圆片——它们逼我在改 Prompt 时优先问「体态有没有漂」，而不是「皮肤高光够不够艳」。

核心文件：elena_character_sheet.html

文件夹里唯一的手写代码是这个 1600×900 的静态页：左侧信息栏（姓名、称号、武器、元素、性格），中间三视图（正 / 侧 / 背，共用 ChatGPT-Image2.png 的不同裁切），右侧表情五态、服装 SVG 分解、色板与世界观短文。字体用 Noto Serif SC + Cinzel，背景是浅蓝网格水印——整体偏「官方设定集」排版，但页脚仍写 Official Character Design · Confidential 只是视觉语气，不代表任何商业项目。

三视图不是三张独立 PNG，而是一张宽图里用 CSS object-position 切出 front / side / back。这样做的好处是：换源图时只替换 ChatGPT-Image2.png 一处；坏处是侧背角度完全依赖源图里是否真有足够像素——若源图只有正面，侧面框里会出现拉伸感，我会在探索阶段直接判失败。

源图 ChatGPT-Image2.png：一张图扛三视图

这是 5 月 18–20 日多轮出图里最终用来进设定表的那张宽构图。我要求模型在同一张里给出可裁切的全身正面与足够宽的左右留白，以便侧面与背面框不至于空。下面放原图全幅，方便你对照 HTML 里的裁切逻辑。

按日期命名的探索图：我在改什么

ChatGPT Image 2026年5月18日 … 到 5月20日 … 共七张 PNG，不是「抽卡凑数」，而是分阶段验收：

  • 5/18 早期 — 先锁脸与发型（长直、浅棕、刘海是否挡眼），服装允许临时简化，只看五官一致性。
  • 5/19 中期 — 加金链、臂环、法杖轮廓；检查纱裙层数是否可读（至少两层透明叠压）。
  • 5/20 后期 — 背景改为浅海或白棚，测试导出后缩略图是否仍像同一个人；失败帧直接删，不进入 HTML。

七张里我保留差异最明显的六张做对比墙；若某张与 ChatGPT-Image2.png 五官冲突，它只留在硬盘上当「反面教材」，不上正文。

设定表里的「硬信息」我怎么用

左栏表格不是装饰。身高 168 cm、元素「水」、武器「潮沙法杖」会反过来约束后续出图：若某张探索图里出现火焰特效或重甲，我会标为离题。色板分主色（象牙白 / 天光蓝 / 海洋蓝 / 深海蓝）、辅色（沙滩米 / 暖沙金）、点缀色（法杖金 / 花冠绿 / 宝石蓝）——改 Prompt 时我只允许在同一行色板里微调饱和度，不允许突然换成霓虹紫发。

世界观段落写的是「碧海群岛」与「潮沙之力」——给以后若写短篇或关卡文案留钩子，但本篇不附游戏机制数值，避免读者以为这是即将发售的 IP。

表情五态：CSS 滤镜而不是五张脸

设定表右侧五个圆片共用同一张脸，用 filter:saturate/brightness/hue-rotate 做「温柔 / 微笑 / 沉思 / 坚定 / 喜悦」的近似。这是刻意的工程选择：我尚未画出五张独立表情稿，但需要在排版上占住位置，提醒未来补图。若你要复刻这套流程，建议最终仍用五张独立 crop 替换滤镜版——滤镜版只适合作个人草稿，不适合对外交付。

我刻意没做的事

本文件夹没有骨骼绑定、Spine 图集、UE MetaHuman、或任何商店可下载的 package.json。没有对外宣称的 Gacha 卡面或 Live2D 工程。平台水印若出现在某张探索 PNG 上，我只作来源记录，不在此教去水印或批量爬图。HTML 设定表也没有接后端——它就是静态文件，方便我整页 iframe 进文章，像 行走循环页 嵌入 walk.html 一样。

和本站其他角色页怎么分工

role-girl 是都市白裙卡牌；girl1 是针织窗景九格；character-turnaround-walk 偏动画管道四视图。艾琳娜线独占 original/game-girl/，避免文件名与叙事混用。以后若做「碧海群岛」第二张角色，我会新开目录，而不是把新脸硬塞进本页 HTML。

维护约定

若我替换 ChatGPT-Image2.png 或改设定表布局，会同步更新本文 JSON 的 dateModified，并在 changelog 写一句。设定表版本号目前标 v1.0——对应 2025 页脚年份是排版遗留，以文件夹内文件日期为准。

若你要复用这套结构

建议固定四件：一张宽构图三视图源、一份 HTML 设定表（信息 + 色板 + 世界观）、按日期留探索 PNG、一篇说明「淘汰理由」的手记。比堆十篇「AI 工作流」更像有人在维护角色线，也方便 AdSense 审核员看出页面主内容是站长写的说明，而不是只有外链或 RSS 标题。
