iOS 26.6 beta 2 已发布：几乎看不到新功能

维护版 · 屏蔽来电上限提醒 · 公开/开发者 beta 安装

2026-06-29 · 本站原创

本文存档 Macworld 标题 iOS 26.6 beta 2 is here, but you won't see much that is new。科技 Hub 本篇解读 Apple 26.6 测试轨道的定位、已知变化与 beta 安装路径；结构化数据见 data/ios-266-beta-2-macworld-snapshot.json。

Apple 已迅速启动下一波 iOS 26 / iPadOS 26 / watchOS 26 / macOS 26 等「26.6」版本测试。Macworld 指出：26.6 预计聚焦 bug 与安全修复，不会带来重大新功能；也可能为 WWDC 26 可能发布的新硬件提供支持。文章于 6 月 15 日更新：第二个 iOS 26.6 beta 已发布——对用户可见的变化依然很少。

26.6 有什么新东西？

2026-06-15（Macworld 更新：iOS 26.6 第二个 beta 发布） · iOS 26.6 / iPadOS 26 / watchOS 26 / macOS 26 等以 bug 修复与安全补丁为主，预计无重大新功能；可能为 WWDC 26 新硬件提供支持。来源：iOS 26.6 beta 2 is here, but you won't see much that is new（Macworld，存档 2026-06-29）。

26.6 已知变化

项目状态
被屏蔽来电上限提醒目前唯一传闻的「新功能」：接近屏蔽来电数量上限时通知用户
抢机自动锁定（开发中）若 iPhone 被从手中夺走可自动锁定；可能进入 26.6，但 beta 2 尚未见到

公开测试版安装步骤

  1. 在 Apple Beta 页面点击 Sign Up，用 Apple ID 注册
  2. 登录 Beta Software Program
  3. 点击 Enroll your iOS device
  4. 打开 设置 → 通用 → 软件更新
  5. 在 Beta Updates 中选择 iOS Public Beta（注册后可能需要稍等才会出现）

开发者测试版安装步骤

  1. 从 App Store 下载 Apple Developer App
  2. 打开 App → Account
  3. 使用常用 Apple ID 登录（免费开发者账号即可）
  4. 在 设置 → 通用 → 软件更新 → Beta Updates 中选择 Developer Beta

为什么 beta 2「几乎看不到新功能」

在 iOS 大版本周期末尾，Apple 常以 x.6 维护轨收尾：修漏洞、稳性能、为即将发布的硬件补驱动/兼容层。Macworld 的 headline 直指这一点——you won't see much that is new 不是 bug，而是产品策略。与 Hub 内 iPhone 17 Pro 购买页存档 对照，硬件营销页与系统维护 beta 属于不同信息层：前者卖 SKU 与 Trade In，后者回答「现在装 beta 值不值」。

传闻功能：屏蔽上限与抢机锁定

目前唯一被点名的「新功能」是：当用户接近屏蔽来电数量上限时收到通知（多数用户可能永远碰不到上限）。另有从手中夺走 iPhone 时自动锁定的能力在开发中，可能进入 26.6，但 beta 2 尚未见到实装迹象。写 SEO 时可并用 iOS 26.6 beta 2、iOS 26.6 blocked calls notification、iPhone anti-snatch lock。

公开 beta vs 开发者 beta

非注册开发者也可通过 Apple Beta Software Program 测试；需 Apple ID 注册并在「软件更新 → Beta Updates」选择 iOS Public Beta。开发者轨可用免费 Apple Developer 账号，通过 App Store 的 Apple Developer App 登录后在同一菜单选择 Developer Beta。注册后 beta 选项可能需要稍等才会出现——详见上文快照中的分步列表。

是否值得在主力机安装？

  • 维护版预期 — 26.6 不是功能大版本；期待新 UI/新 App 的用户会失望。
  • 风险 — beta 可能带来续航、银行 App、CarPlay 等兼容问题；主力机建议等正式版。
  • 谁适合装 — 开发者、媒体、需要验证安全补丁或特定回归的测试者。
  • 生态同步 — iPadOS / watchOS / macOS 26.6 通常同批测试；多设备用户需分别更新。
