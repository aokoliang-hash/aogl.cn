EatToday 今天吃什么：家庭点菜 × 今日菜单分享手记

这是 aogl.cn 上的一篇个人原创开发手记，素材全部来自 original/eattoday/（2026-08-14 归档）。EatToday（今天吃什么）是本人开发的 App（页脚署名 © kolang），入口：http://eattoday.aogl.cn/——把家里每晚「今天吃什么 / 谁做饭」的决策成本，压成一条可分享的家庭今日菜单。一人或多人点菜，做饭的人打开当日清单，按食材、步骤和可选视频外链下锅。本文不是转载软文，而是作者按真实截图拆解：点菜页、三餐槽位、菜谱详情、空状态引导、家庭房间邀请码，方便检索「家庭今天吃什么 App」「共享家常菜菜单」「免注册家庭点菜」等长尾词。

产品定位：压缩家庭决策成本

多数「菜谱站」优化浏览；EatToday 优化另一种失败模式：家里其实会做菜，但今晚没人愿意拍板。README 写得很直接——用三步砍掉「吃什么 / 谁做」的扯皮：

  1. 点菜 — 按分类或搜索家常菜，加入早/午/晚。
  2. 今日菜单 — 生成带日期的清单，做饭的人一眼能照单执行。
  3. 分享 — 把房间链接或邀请码发给灶台前的人。

它更接近轻量家庭协作工具，而不是 SEO 菜谱农场。只有美图没有「今日清单」，每晚还得重谈；只有群聊没有三餐槽位，消息一刷就丢。EatToday 用顶部双页签钉住两端：点菜与今天吃。

角色：点菜的人 / 做饭的人 / 管理员

  • 点菜的人 — 要快浏览、加入今日、能分享。
  • 做饭的人 — 要今日清单、食材步骤/视频、做中/已做状态。
  • 管理员 — 维护分类、菜式、食材、步骤与视频外链。

这些角色来自 README.txt，不是编出来的人设。产品刻意支持昵称参与、弱注册：创建或加入家庭房间即可点菜。用家庭真实场景换掉企业式登录墙——爷爷奶奶和小孩最容易死在「先填邮箱」那一步。

点菜页：搜索、分类、三餐槽位

「点菜」页在页签下有三枚餐次胶囊：早餐 / 午餐 / 晚餐。当前餐次会改写每张菜卡按钮文案（如「加入早餐」）。搜索框占位：「搜菜名，比如番茄炒蛋」——番茄炒蛋既是品牌菜名，也是搜索示例，语气一致。分类芯片含全部、家常炒菜、汤羹、蒸煮炖、主食面点、凉菜小吃、下饭硬菜。列表可「加载更多（已显 24/80）」，避免首屏一次塞八十张卡。

归档可见菜名包括土豆烧排骨、鱼香茄子、蒜蓉烤排骨、红烧鸡翅根、啤酒鸭、虎皮青椒、凉拌海带丝、皮蛋豆腐等。正文重复这些实体是有意为之：具体家常菜长尾词可以落到「既有产品说明又有菜单工具」的页面，而不是薄关键词表。

菜谱详情：时长、视频，再加入某餐

打开「土豆烧排骨」可见标题「菜谱详情」、主图、时长芯片「大约 60 分钟」、视频教程卡，以及与当前餐次一致的橙色主按钮「加入早餐」。做饭路径很清楚：先看懂怎么做，再提交到今日看板。视频是可选教学辅助，产品核心仍是共享菜单契约，而不是播放量。

今天吃：用空状态教回路

示例「今天吃」页显示 敖家 · 2026-08-14，右侧红色「分享给家人」。早/午/晚计数为 0。空卡片不是空白——它在教：「选几道家常菜，做饭的人一眼就知道做什么」，并提供「去点早餐的菜」。好的空状态等于嵌在 UI 里的产品文档。对 AdSense 与人工审核也有用：截图证明这是设计过的协作流程，不是洗稿菜谱堆。

有菜之后，做饭的人应按用户故事看到分餐清单，并把状态改为做中 / 已做。状态闭环解决协调问题：点菜的人少问「好了没」，做饭的人少猜「哪条微信才是最终菜单」。

家庭房间：创建、邀请、加入

没有房间时进入房间页：「还没有家庭房间」，可创建房间或输入邀请码加入。加入可填昵称（占位「吃货」）与邀请码或粘贴分享链接。这是 EatToday 相对个人备忘 App 的多人边界。同站产品 WordPet（wordpet.aogl.cn）解决单人学习习惯；EatToday 解决围绕一口灶的多人协调习惯。

把交互产品放在兄弟域名 eattoday.aogl.cn，与 aogl.cn 静态编辑站分界：长文 SEO 在 aogl.cn 首屏 HTML；点菜状态与房间 cookie 留在独立宿主。线上演示请优先使用当前可用的 http:// 入口，文案不虚构 HTTPS 可用性。

不愿稀释的用户故事

  1. 作为家人，我可用昵称创建或加入房间并开始点菜，不必长注册。
  2. 作为点菜的人，我可按分类/搜索找菜，看食材步骤，加入今日某餐。
  3. 作为点菜的人，我可复制房间链接或邀请码给做饭的人。
  4. 作为做饭的人，我可在做饭模式看今日列表并标记做中/已做。
  5. 作为管理员，我可上下架菜谱、编辑教程与视频链接。

趁 UI 还热马上写手记，才能诚实：照抄界面文案（点菜、今天吃、加入午餐、分享给家人），不承诺未截到的路线图，也不把产品写成营养/医疗建议。它是决策与协调工具。

无障碍与 SEO 清单

  • alt 写可见 UI 实体（餐次、菜名、按钮），禁止「图片1」。
  • 正文重复 EatToday、今天吃什么、App 地址 http://eattoday.aogl.cn/、点菜、今天吃、家庭房间、邀请码、土豆烧排骨、番茄炒蛋。
  • 外链加 rel="noopener noreferrer"；完整叙事放在首屏 HTML。
  • 引用空状态文案，让爬虫在零点菜演示时也能理解回路。
