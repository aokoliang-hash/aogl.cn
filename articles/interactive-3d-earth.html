交互式 3D 地球浏览器

Three.js · 云层与大气光晕 · 轨道控制

2026-05-13 · 本站原创

这是一篇本站原创的交互式 3D 地球技术展示，底层使用 WebGL 与 Three.js（r128）。贴图组合包含类 NASA「蓝大理石」地表、凹凸（bump）地形、海洋高光（specular）、独立云层球体，以及自定义大气边缘光（rim）着色器，在深色背景上层次清晰，适合地理科普、科技品牌落地页或作品集「视觉锚点」。

在线体验 3D 地球

按住鼠标拖拽可环绕观察；滚轮缩放。全程在浏览器内运行，无需安装插件。

为何利于 SEO

  • 使用 语义化标题与段落（h2、h3、figure、figcaption），明确主题词：3D 地球、WebGL、Three.js、云层、大气。
  • iframe 前后均有原创说明文字，即使画布在 iframe 内，页面仍有可被索引的正文。
  • iframe 使用 loading="lazy"，从列表页进入时对首屏性能更友好。

实现要点（给开发者）

渲染管线采用 WebGLRenderer，主方向光模拟太阳、辅以环境光；相机交互为 OrbitControls。大气层为略大于地表的透明球体，片元着色器按视角与法线夹角混合边缘高亮与淡蓝色调，呈现经典「暗淡蓝点」观感，而无需复杂后处理。

若站点做多语言，可为每种语言配置独立标题与摘要（本站做法），共享同一份交互资源，兼顾长尾关键词覆盖与维护成本。

为什么把这个 Demo 放在 aogl.cn

地球最初只是 original/earth/ 下一份独立 HTML，后来才包进这篇文章。拆分很重要：iframe 是稳定资源，我可以换贴图而不改七种语言外壳；本页承载 AdSense 审稿人真正会读的叙述——试过什么、否决了什么、哪份文件为准。这就是工作流里「只有嵌入」与「有实质内容的页面」的差别。

第一版与我扔掉的东西

早期原型是单张漫反射贴图的 UV 球，没有云层。截图还行，但绕转时塑料感很重：海洋没有高光断裂、没有边缘光、晨昏线是硬切。我也试过本地加载六张 8K 分片；中端笔记本第一次交互会卡约两秒等贴图解码。现在这版用可预期加载换最高分辨率：CDN 托管约 2K 级贴图、一层云壳、轻量 rim 着色器，而不是完整后处理栈。

我当作权威源的文件

  • original/earth/interactive-3d-earth.html — 嵌入目标（OrbitControls、渲染循环）。
  • 同目录下的 earth-blue-marble.jpg、earth-topology.png、earth-water.png、earth-night.jpg、earth-dark.jpg、night-sky.png 等通道素材（演示源码注释里也会写引用路径）。
  • 封面静帧可用 Gemini_Generated_Image_i67zumi67zumi67z.png 或站内其它英雄图，避免每次都靠实时 WebGL 截图做社交卡片。

更新贴图时我先改 Demo，必要时重截图，再 bump 文章 JSON 的 dateModified，让人和爬虫看到同一修订日。

交互与无障碍取舍

嵌入内以鼠标环绕为主；触摸手势我考虑过但刻意收窄范围，好让脚本可读。文章页本身键盘友好：标题、figure/figcaption 与本段正文都在 iframe 外。若你做类似页面，请复用这一模式——绝不要把唯一说明文字塞进画布文档里。

接下来可能做的

有时间的话，我会在嵌入内加「已知限制」短列表（极点拉伸、无夜灯），并外链到 八大行星贴图合集，那里记录太阳系其余等距柱状素材。眼下本页任务是证明地球 Demo 有人维护，而不是去和 NASA 官方应用抢位。

大气着色器一句话

边缘光是 Fresnel 加权混合：正对相机处染色更少，掠射角取饱和蓝。强度刻意压低，好在深色文章背景下可读，又不吹爆昼侧非洲大陆。没有 bloom——大气壳只多一次绘制调用——中端 GPU 在长文里嵌 iframe 时仍能保持流畅。

贴图管线与 CDN

颜色、凹凸、高光贴图从演示源码里的稳定 HTTPS 地址加载。CDN 抖动时地球仍可能以平色渲染，但失去起伏；我在注释里写明，免得未来的我把「坏了的着色器」当成根因，其实只是 bump 404。高光只遮罩海洋，避免大陆看起来湿漉漉。云层转速略快于地表，用廉价视差分离，比单层壳更耐看。

地球页发布检查清单

  • iframe 外正文解释技术栈、限制与文件路径。
  • 列表页 iframe 用 loading="lazy"；直达本 URL 时再考虑 eager。
  • Demo 贴图或控件变更时 bump dateModified。
  • 交叉链到行星贴图合集，给需要真实历表数据而非玩具地球的读者。

这份清单与我在其它合成类文章里的做法一致——十二篇原创之间统一的维护者口吻，比孤立做出一个完美 WebGL Demo 更重要。

目录里还有什么

original/earth/ 还放着 earth-day.jpg、ChatGPT Image11_35_51.png 等试验静帧与备选通道。它们帮助我做 A/B 对比，但默认嵌入只加载演示 HTML 当前引用的那套贴图，避免文章页一次拉齐所有高清图。若你 fork，请先读 interactive-3d-earth.html 里的路径注释，再决定要不要换成本地相对路径。
