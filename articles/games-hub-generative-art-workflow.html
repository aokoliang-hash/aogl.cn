游戏 Hub 快讯 × 生成式角色美术：个人工作流备忘

games.html Hot mix · 非官方美术抓取 · articles 归档

2026-06-18 · 本站原创

本文把 aogl.cn 上两个常分开看的部分连起来：游戏 Hub（Steam / 御三家 / 发行商第一方 RSS）与原创文章里归档的生成式角色 look-dev。是个人周日流程——不是评测站、不是美术抓取教程，也与任何商店无隶属关系。

周日循环（白话）

  1. 跑完 fetch-hub-news 后打开 games.html 看 Hot mix。
  2. 挑美术向标题（重制、角色预告、风格指南）；纯服务器维护类通常止步于 Hub。
  3. 在 Midjourney 或 Gemini 问窄问题：只要「配色 + 剪影」，不「复刻这张官方 KV」。
  4. 探索图存 original/项目名/ 并带日期；偏离身份锚点的直接弃。
  5. 文件夹成熟后写一篇诚实手记（HTML 设定表、contact sheet 或视频）。

明确不做的事

  • 不抓商店美术 — KV 与缩略图留在官方 CDN，本站不镜像。
  • 无破解 / APK 索引 — 与游戏 Hub 排除项一致。
  • 不写「必玩十大」 — 本站流量策略是维护者归档，不是泛游戏榜单。
  • 不堆提示词教程 — 文章讲取舍，不是 SaaS 说明书。

本站已有案例

  • 艾琳娜 · 海风之诗 — 海岛祭司 HTML 设定表。
  • 艾琳娜配色与仪式 UI — 设定表维护手记。
  • 角色卡牌视觉练习 — 白裙 contact sheet。
  • 角色设计手记 — 四视图与行走循环。

均非某商业游戏的官方同人声明，而是「跟着行业视觉做练习」的归档。

何时停在 RSS 就够了

若标题只是停服维护，不必开生成工具、也不必新文章。游戏页作为阅读轨已有价值；只有产出可检查的 PNG / HTML / MP4 并写好范围段时，才新增 articles URL。

工具书签

视频：Runway；写表：Cursor；长文：Claude；查陌生引擎名：Perplexity；全集：攻略索引。

发文章前自检

  1. 首段写明虚构 / 演练范围，非真实房源或商品。
  2. 英文正文约 800 词或同等深度，含图 / 嵌入。
  3. original/ 文件名稳定且在 figcaption 中可查。
  4. 内链到相关 Demo（窗景合成、WebGL、其它角色线）。
  5. 改资产则更新 dateModified 与 changelog。

为何放在 articles 而非 games.html

Hub 页保持短导语 + 外链；长流程会稀释定位并带来「薄页」风险。可教叙事放文章，games 页继续当周日标题条。
