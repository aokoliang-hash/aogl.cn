WordPet 背单词养宠物：石猿进化 × 教材同步词书手记

产品定位：习惯回路，而不是再堆一套单词表

市面上不缺「认识 / 不认识」闪卡。WordPet 的差异在于把学习结果喂进可见的养成反馈：背词 → 获得经验 → 宠物进化 / 换装出战。登录页把路径压成五步：

  1. 注册登录 — 建立可续期的账号，而不是一次性访客状态。
  2. 领养宠物 — 情感锚点（石猿、哪吒等）先于长列表词书。
  3. 每日打卡 — 用日期节律把词汇量变成习惯，而不是一次背完三百词的突击。
  4. 获得经验 — 把「认识」反馈量化成 XP，对接宠物等级与战力。
  5. 进化成长 — 灵火蛋期、金阶、星级等视觉层级，让进步可感知。

从用户心理上说，这是外在诱饵（萌宠）服务内在目标（教材词汇）：家长关心同步词书，孩子关心出战与对话。产品若只做其一，要么变成枯燥词表，要么变成与学习脱钩的扭蛋。WordPet 把两者绑在同一底栏：首页 / 学习 / 宠物 / 我的。

词书学习：教材对齐比「通用词库」更重要

「词书学习」页顶部钉住主词书示例：沪教版 · 五年级上册。分类标签含教材同步（默认）、通用年级、其它；教材版本横向滚动可见人教 PEP（2026 秋）、外研版 NEW、沪教版 NEW；学段可在小学 / 初中间切换。列表卡片展示单元数、进度条（如 13%、4%）与「设为主词书（用于每日打卡）」按钮。

对小学英语而言，「进度」若不以课本单元为轴，打卡就会和课堂考试错位。我刻意在正文重复人教 PEP、沪教版、外研版、五年级上册、三年级上册等实体名，方便家长用教材名称检索。把某一册设为主词书后，「今日单词」来源条会显示同一词源（见下），保证打卡队列与主词书一致。

今日单词：最小阻力闪卡

「今日单词」界面示例中，进度为 1 / 10，词源为沪教版五年级上册。中心卡片展示例词 pilot、/ˈpaɪlət/、释义「n. 飞行员」与例句 The pilot flies the plane.，旁有发音按钮。底部双按钮为不认识 ✕ / 认识 ✓——经典间隔复习入口，刻意做得极大，适配拇指区。

设计取舍上，我偏好当天量小、反馈清晰（10 词量级），而不是一次 100 词的劝退队列。经验值应绑定「认识」与纠错后再认识，而不是单纯翻页；否则宠物 XP 会与真实记忆脱节。反馈入口「意见反馈」放在闪卡页底部，方便学生报错音标或例句。

我的宠物：哪吒灵火蛋与出战

「我的宠物」顶部轮播可见哪吒、石猿、墨韵龙等。示例中哪吒为出战 SSR：灵火蛋期、Lv.4、金-1、战力 95、经验 660/1000，文案「灵火裂蛋，炽热气息涌动」。卵壳裂纹与火焰粒子把「还在养成」写成画面，而不是一张已定型立绘——这对「进化可期待」至关重要。

宠物命名混合神话 IP 感（哪吒、石猿、墨韵龙）与学习语义（见宠物库中的单词猫、知识犬），让收藏既好玩又可记。战力与等级是给孩子看的「分数板」；真实学习仍应回看词书进度条，避免只追求扭蛋。

宠物对话：口语练习的轻入口

「宠物对话」把出战宠放在中间，哪吒卵上方气泡出现中英混合提示（例：Apple is a sweet name! 并提到敖丙与明日背单词）。底部为按住说话，松开发送的麦克风主按钮，旁有键盘与扬声器等辅助。这是把语音输入嵌进养成场景，而不是另开一个冷冰冰的口语考场页。

实现上需注意：弱网、麦克风权限拒绝、儿童隐私与内容审核。产品文案宜保持短、鼓励、可英中混排；长作文题不适合塞进气泡。对 SEO，本文强调「宠物对话」「按住说话」等界面词，覆盖语音学英语相关检索。

宠物库：稀有度与「去召唤 / 设为出战」

「宠物库」网格展示白蛇、麒麟、白泽、玉兔、朏朏、石猿、单词猫、知识犬、老虎等，稀有度标签含 SSR / SR / S / A。未拥有显示「去召唤」，已拥有显示「设为出战」。石猿标为 SSR「已拥有」，与品牌吉祥物呼应。

收集系统的健康边界：召唤消耗不应压过每日背词；否则产品会滑向付费扭蛋叙事。WordPet 的主路径仍应是主词书打卡 → XP → 进化，召唤是支线皮肤。写作本稿时，我把「单词猫 / 知识犬」当作可检索的趣味关键词，提醒搜索引擎这是学习向养成，不是泛二次元抽卡站。

信息架构小结（四栏底导航）

  • 首页 — 今日任务与入口聚合。
  • 学习 — 词书 + 今日单词（教材对齐的主战场）。
  • 宠物 — 出战、对话、图鉴（情感与留存）。

该结构对小学生拇指操作友好，也方便家长一眼找到「换词书」。与本站其它 Demo（角色转身、WebGL 地球）不同，本篇更贴近 EdTech / 小学英语 / 习惯养成 关键词簇，适合作为 AdSense 审核时的「真实产品原创说明」样本之一。
