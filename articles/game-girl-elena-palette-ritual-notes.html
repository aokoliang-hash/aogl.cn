艾琳娜配色与仪式 UI：HTML 设定表维护手记

色板硬字段 · 五表情占位 · v1.0 维护约定

2026-06-18 · 本站原创

本文是 海岛祭司艾琳娜 · 海风之诗 的续篇。首篇介绍 HTML 设定表、三视图源图与 5/18–5/20 探索图；这里写我日常真正维护的内容：配色硬字段、五个表情占位与设定表里的「仪式 UI」语气——仍是个人归档，不是商业游戏 SKU。

为什么另开 URL 而不改首篇

把配色规则塞进首发文会淹没「角色色板」「HTML 设定表维护」等长尾。拆分后，首篇负责「是谁、有哪些文件」，本篇回答「改一个颜色怎样不弄坏版式」。做法类似 WebGL 地球 与 真实行星贴图 分两页。

左栏色板硬字段

主色（象牙白 / 天青 / 海蓝 / 深海蓝）、辅色（沙米 / 暖金）、强调色（杖金 / 冠绿 / 宝石蓝）不是装饰——是淘汰标准。新图若头发偏霓虹紫、裙摆变大红，在换 ChatGPT-Image2.png 之前直接弃用。色块上的 hex 会抄进提示词；我不从 PNG 自动吸色（曾有一次压缩导致肤色漂移）。

五个表情圆：CSS 滤镜占位

每个情绪圈复用脸部裁剪 + filter，是刻意的技术债：先让版式可发布，再补五张手绘表情。对外交付前必须换成真实裁剪——本站保留滤镜是为了固定 UX 槽位（温柔 / 微笑 / 沉思 / 坚定 / 喜悦），避免日后插图到位时布局跳动。

仪式 UI 文案

页脚「Official Character Design · Confidential」营造 AAA 管线感，在本站仅表示版式语气：无 NDA、无发行商、无 SKU。若开源 HTML，会在页脚上加一句免责；目前海岛幻想与假保密栏的反差也是 Demo 的一部分。

维护约定（v1.0）

  1. 更换 ChatGPT-Image2.png → 必须重查三视图的 object-position。
  2. 改 hex 色板 → 更新文章 dateModified 与 changelog 一条。
  3. 加第六个表情 → 先改 HTML 网格，再画图。
  4. 不在此页嵌 WebGL / Live2D；动画另开文章并写清范围。

配套工具书签

出图探索：Gemini、Midjourney 备忘。改表代码：Cursor。模型政策：快讯。

与游戏 Hub 的关系

我在 games.html 扫第一方标题，再回到 original/game-girl/ 做个人美术实验——流程见 游戏 Hub × 生成式角色美术工作流。商店 RSS 不会自动改设定表。

边界

无骨骼、无引擎包、无抽卡数值。第三篇只会在新实物（例如手绘五表情）上线时出现，而不是为堆关键词。
