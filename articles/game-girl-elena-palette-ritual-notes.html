艾琳娜配色与仪式 UI：HTML 设定表维护手记

色板硬字段 · 五表情占位 · v1.0 维护约定

2026-06-18 · 本站原创

本文是 海岛祭司艾琳娜 · 海风之诗 的续篇。首篇介绍 HTML 设定表、三视图源图与 5/18–5/20 探索图；这里写我日常真正维护的内容：配色硬字段、五个表情占位与设定表里的「仪式 UI」语气——仍是个人归档，不是商业游戏 SKU。

为什么另开 URL 而不改首篇

把配色规则塞进首发文会淹没「角色色板」「HTML 设定表维护」等长尾。拆分后，首篇负责「是谁、有哪些文件」，本篇回答「改一个颜色怎样不弄坏版式」。做法类似 WebGL 地球 与 真实行星贴图 分两页。

左栏色板硬字段

主色（象牙白 / 天青 / 海蓝 / 深海蓝）、辅色（沙米 / 暖金）、强调色（杖金 / 冠绿 / 宝石蓝）不是装饰——是淘汰标准。新图若头发偏霓虹紫、裙摆变大红，在换 ChatGPT-Image2.png 之前直接弃用。色块上的 hex 会抄进提示词；我不从 PNG 自动吸色（曾有一次压缩导致肤色漂移）。

五个表情圆：CSS 滤镜占位

每个情绪圈复用脸部裁剪 + filter:saturate/brightness/hue-rotate，是刻意的技术债：先让版式可发布，再补五张手绘表情。对外交付前必须换成真实裁剪——本站保留滤镜是为了固定 UX 槽位（温柔 / 微笑 / 沉思 / 坚定 / 喜悦），避免日后插图到位时布局跳动。

仪式 UI 文案

页脚「Official Character Design · Confidential」营造 AAA 管线感，在本站仅表示版式语气：无 NDA、无发行商、无 SKU。试玩者说有页脚栏设定表更「像真的」——即便没有保密协议。若开源 HTML，会在页脚上加一句免责；目前海岛幻想与假保密栏的反差也是 Demo 的一部分。

维护约定（v1.0）

  1. 更换 ChatGPT-Image2.png → 必须重查三视图的 object-position。
  2. 改 hex 色板 → 更新文章 dateModified 与 changelog 一条。
  3. 加第六个表情 → 先改 HTML 网格，再画图——绝不反过来。
  4. 不在此页嵌 WebGL / Live2D；动画另开文章并写清范围。

配套工具书签

出图探索：Gemini、Midjourney 备忘。改表代码：Cursor。模型政策提醒：快讯。这些链接不是背书，是我的目录条目。

与游戏 Hub 的关系

我在 games.html 扫第一方标题，再回到 original/game-girl/ 做个人美术实验——流程见 游戏 Hub × 生成式角色美术工作流。商店 RSS 不会自动改设定表；仍需人合并决策。

边界

无骨骼、无引擎包、无抽卡数值、无配音选角。第三篇只会在新实物（例如手绘五表情）上线时出现，而不是为堆关键词。

服装 SVG 格：为何用内联矢量占位

设定表里的服装拆解用简单内联 SVG 剪影——不是最终服装平面图。它们存在的意义是：以后换 PNG 裁剪时，版面宽度仍稳定。每格标签写「主服 / 腰带 / 头饰 / 法杖」中文，因为维护时的第一读者是我自己；英文文章向访客解释意图。我拒绝把栅格服装片嵌进 SVG 层；栅格只属于三视图条。

强调色硬淘汰规则

  • 杖金（#D4AF37） — 生成结果若偏橙铜，弃；法杖必须读成金属，不是木头。
  • 冠绿（#2E8B57） — 只用于藤冠；绝不渗进头发高光。
  • 宝石蓝（#4169E1） — 留给潮沙杖上的宝珠；不复用到瞳孔或唇彩。

5 月 19 日有一张探索图把宝石蓝涂到瞳孔上，我本地留作反例，但未放进首发文的公开图库。

表情滤镜数值（占位时代）

当前 CSS 在共享脸部裁剪上用轻度滤镜：温柔（亮度 +5%）、微笑（饱和 +10%）、沉思（亮度 −8%）、坚定（色相旋转 5deg）、喜悦（饱和 +12%）。这些数字不是美学目标——只是在手绘圆盘到位前防止布局跳动。写在这里，是为了换成真实 PNG 时能 diff。

换图时的三视图检查清单

换 ChatGPT-Image2.png 后，我会按顺序核：正面脸部中心是否仍落在 object-position 目标；侧面耳线是否被裁切；背面发冠是否露出藤蔓。任何一处偏了，先改 CSS 裁剪，再考虑重出图。设定表是维护面，不是「再生成一次就好」的借口。

中文加厚：调色拒绝规则与设定表

elena_character_sheet.html 把调色、表情滤镜与服装格子放在同一页，是为了避免「散图文件夹」无法被审核员读懂。金色点缀、冷绿阴影、群青辅色一旦同时抢戏，角色就会像贴纸而不是可落地的设定。我在手记里写拒绝规则，不是为了玄学，而是给未来的自己一份可执行的检查表：换一版图之前，先看色相是否破坏轮廓可读性。
