太阳系八大行星贴图集：equirectangular 纹理与地球多通道素材

Mercury–Neptune · earth-blue-marble · Interactive-3D-Earth-video.mp4

2026-05-26 · 本站原创

这篇是 aogl.cn 归档的第 11 篇原创手记，素材在 original/major-planets8/。文件夹是一套太阳系八大行星可视化贴图包：七颗外行星与地球各自一张（或多张）2:1 等距柱状（equirectangular）纹理，外加地球专用的凹凸、夜景、水面高光通道，几张适合封面用的 Gemini 风格整球渲染图，以及一段 Interactive-3D-Earth-video.mp4 录屏。不是 NASA 官方数据门户，也不卖素材包授权；只记文件名、用途和与站内其他 Demo 的分工。

文件夹里有什么

  • 行星 equirectangular 贴图 — Mercury.png、Venus.png、Mars.png、jupiter.png、saturn.png、uranus.png、neptune.png
  • 地球多通道 — earth-blue-marble.jpg、earth-topology.png（凹凸）、earth-water.png（高光/水体）、earth-night.jpg（夜景灯光）、earth-dark.jpg（暗面或合成辅助）
  • 环境 — night-sky.png 星空背景
  • 封面级渲染 — 六张 Gemini_Generated_Image_*.png（水星、金星、火星、木星、土星、天王星、海王星等整球插画风格）
  • 演示录屏 — Interactive-3D-Earth-video.mp4

标题与段落里自然出现 solar system textures、planet equirectangular map、Three.js sphere texture、blue marble earth 等检索词，均对应真实文件，不做隐藏堆砌。

为什么用 2:1 等距柱状图

在 Three.js 里把贴图包在 SphereGeometry 上时，宽高比 2:1 的 equirectangular 图能在极点变形可控的前提下覆盖整球。木星、土星这类气态巨行星横向条纹会在经度 0°/360° 接缝处对齐；岩石行星（水星、火星）则要检查陨石坑射线是否在接缝处断开。我导出前会放大接缝带看一眼，避免上线后观众拖拽旋转时出现竖线闪动。

本站 交互 3D 地球 已用类似思路做外观测地球：蓝大理石底色 + 凹凸 + 高光 + 云层。本篇 major-planets8 把其余七颗行星补齐，方便你做太阳系沙盘、科普页轮播或教学用 HTML，而不必每次重新找贴图。

类地行星贴图：水星、金星、火星

Mercury.png 灰褐色撞击坑密集，左侧可见年轻撞击坑的射线纹——适合讲「最接近太阳的岩石行星」与 MESSENGER 任务时代的全球制图。Venus.png 呈雷达反照的金色地形，亮区对应高原（如伊师塔高原、阿佛洛狄忒高地），暗区为火山平原；提醒读者金星表面被浓硫酸云层遮住，贴图代表的是雷达看到的「地表」，不是可见光照片。Mars.png 铁锈色外壳上横贯水手号峡谷系统，两极有白色极冠——与 Gemini_Generated_Image_6wdi276wdi276wdi.png 的插画版火星可对照：一张偏科学制图，一张偏科普封面。

气态与冰巨行星：木星到海王星

jupiter.png 展示大红斑与多条云带，是典型的木星大气 equirectangular 展开；贴到球体上时，大红斑纬度要和你场景里的光照方向一致，否则「风暴位置」会显得假。saturn.png 除球面云带外，环系统往往要单独几何体（环面或透明贴图），不要强行画进 2:1 展开图里——本站 Gemini 版土星（Gemini_Generated_Image_79swyt79swyt79sw.png）就是把环做成封面英雄图的好例子。

uranus.png 青绿色平滑大气，适合配合「躺着自转」的科普文案；neptune.png 深蓝条带与大暗斑，风速极强的冰巨星叙事。四张气态/冰巨星贴图如下，可直接下载复用。

地球：五张图组成「多层地球」

地球是唯一同时提供多通道的行星，这也是文件夹里最「重」的一组资产：

  • earth-blue-marble.jpg — 白天地表反照，科普页最常用
  • earth-topology.png — 灰度凹凸，驱动法线/位移
  • earth-water.png — 海洋镜面高光遮罩
  • earth-night.jpg — 城市夜灯，可与白天做混合 shader
  • earth-dark.jpg — 暗部或合成辅助，避免夜灯在昼侧漏光

若你只想要一颗「能转、能缩放」的地球，优先看文章 交互 3D 地球 里的 iframe 演示；major-planets8 提供的是可替换的源贴图，方便你 fork 后改路径或降分辨率上 CDN。

星空背景 night-sky.png

night-sky.png 用作场景后景或 Scene.background 的 equirectangular 环境图，把行星放在暗星场里，避免纯色 WebGL 背景显得像未完成的 debug 视图。分辨率不必与行星贴图相同，但色温要偏冷、略压暗，以免抢过行星本体的对比度。

Gemini 风格整球图：给封面与 Open Graph 用

六张 Gemini_Generated_Image_*.png 不是 equirectangular 展开，而是正圆整球 + 浅灰背景的插画式渲染，适合首页卡片、社交分享缩略图或文章 hero。它们与科学贴图并存：贴图负责「可绕转的球」，Gemini 图负责「一眼认出是哪颗星」。下文选三张代表内行星、巨行星与冰巨星；其余文件仍在目录中可自行对照。

演示录屏 Interactive-3D-Earth-video.mp4

录屏展示的是地球 WebGL 交互（拖拽、缩放、大气边缘光），说明这套地球通道最终如何进浏览器。行星贴图本身不在此视频里逐一旋转，但地球管线与文件夹命名一一对应，便于你对照 earth-*.jpg/png 文件。

和本站其他太空 Demo 的边界

Velmora 是另一套太阳系探索 UI 概念；交互 3D 地球 只聚焦一颗地球；高铁车窗风景 与 公寓 360° 是室内/交通框景，不是行星尺度。本篇 major-planets8 的定位是可下载的行星贴图源 + 地球多通道 + 封面渲染，三条线并列在首页「本站原创」轮播，避免访客以为全站只有一个地球 Demo。

我刻意没做的事

未包含冥王星或小行星带贴图；未提供克卜勒轨道数值仿真；未声称数据来自某一架望远镜的实时下行。商用太空教育产品需自行核对科学表述与版权；Gemini 插画不可当作任务级科学制图。

若你要复用 major-planets8

  1. 每颗行星一颗 SphereGeometry + equirectangular map；地球额外挂 bumpMap、specularMap 与夜灯混合。
  2. 土星、天王星、海王星的环单独建模，别挤进 2:1 贴图。
  3. 用 night-sky.png 做背景，文章页用 800 字以上手记写清文件分工——比只放下载链接更有利于 SEO 与 AdSense 对「实质性内容」的判断。

部署时保持 original/major-planets8/ 与 HTML 相对路径不变，GitHub Pages 与本地 WAMP 才能共用同一套链接。
