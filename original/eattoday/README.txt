# 产品说明 · 今天吃什么

## 目标

解决「家里每天不知道吃什么、谁做饭」的决策成本：一人或多人点菜 → 生成「今日菜单」→ 分享给负责做饭的人按单做菜。

## 角色

| 角色 | 诉求 |
|------|------|
| 点菜的人 | 快速浏览菜谱、加入今日菜单、分享给家人 |
| 做饭的人 | 打开链接看今日清单、按教程/视频做菜、标记进度 |
| 管理员 | 维护分类、菜式、食材、步骤、视频外链 |

## 用户故事

1. 作为家人，我可以创建或加入「家庭房间」，用昵称参与点菜，无需注册。
2. 作为点菜的人，我可以按分类/搜索找到菜，查看食材与步骤，加入今日菜单。
3. 作为点菜的人，我可以复制房间链接或邀请码发给做饭的人。
4. 作为做饭的人，我可以在做饭模式中看到今日菜列表，并把状态改为做中/已做。
5. 作为管理员，我可以在后台上下架菜谱、编辑教程与视频链接。
