このサイトについて

aogl.cn は生成AIの個人メモです。公式ブログやドキュメントへの入口をまとめ、リンクは新しいタブで開きます。本文は抜粋や短評が中心で、商用レビューではありません。価格・地域・規約は必ず各社公式で確認してください。

下の「内容の柱」はページ内 RSS の区分に対応し、「ツール一覧」は会話・画像・動画・コードなど用途別によく使う公式サイトへのショートカットです。リンク切れ・名称変更・掲載取下げは GitHub Issue に URL と理由を書いてください。余裕があれば直します。

当サイトはニュースサイトではありません。長文は別の場所で；一覧や短報では日付と出所をできるだけ明示します。連絡先は お問い合わせ をご覧ください。
