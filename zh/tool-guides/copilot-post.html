Copilot 是我在 Edge / Windows 裡想快速要一個帶網頁語境的答案時開的入口，不必先開完整 Claude 會話。見首頁工具目錄；非微軟背書。

維護本站時何時用

  • 改構建腳本前先概括長篇微軟 / GitHub 文檔。
  • 本地 WAMP 測試時查 Windows / API 變更。
  • 起草 changelog 短句再進 git 手改。

全倉庫重構用 Cursor；要引用來源用 Perplexity。

五步流程

  1. 從下方按鈕進 copilot.microsoft.com。
  2. 確認登錄的是預期微軟賬戶。
  3. 只貼非機密片段。
  4. 有用結論抄進自己的筆記，不自動發站。
  5. 價格與地區以微軟官網為準；本頁核對 2026-06-18。
