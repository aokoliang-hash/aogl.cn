對話與大模型

說明：本頁為 aogl.cn 書籤站整理的工具簡介，非廠商官方文檔；功能與價格以官網為準。

我把 Claude 放在首頁工具目錄對話類前排，是因為寫長文修訂、靜態站改動二審時常用它——不是因為每條榜單都排第一。本頁記錄的是我在 aogl.cn 的書籤用法，不是商業評測。

我什麼時候開 Claude

  • 長文檔 — 貼 hub JSON 或文章片段，先要結構意見再改 HTML。
  • 語氣保留的改寫 — 英文 description、changelog 句子，要完整句而不是堆關鍵詞。
  • 讀代碼 — 讓陌生構建腳本用白話解釋；實現仍以倉庫為準。

多文件倉庫內改代碼我會換 Cursor；要快速出文章頭圖類多模態草稿會用 Gemini。

五步備忘流程

  1. 從本頁進官方 claude.ai（不用來路不明的鏡像）。
  2. 確認模型選擇與賬戶檔位和官網一致。
  3. 只貼非機密片段——不含 API 密鑰或客戶隱私。
  4. 有用結論手抄進 data/articles/fragments/ 或 changelog。
  5. 大版本發佈先看 Anthropic 原文；同步後可在本站 快訊索引 找到摘要鏈。

定價與地區

套餐、額度、可用地區以 Anthropic 頁面為準。本指南只寫核對日期，不緩存價格。要走 API 請讀開發者文檔，不要以本備忘頁代替。

不適合當…

  • 強依賴實時全網檢索的入口（我會換搜索型工具）。
  • 無人值守批量抓取或付費牆全文（本站不做）。
  • 醫療、法律、投資決策依據（請諮詢持證專業人士）。
