Cursor

編程與 IDE

說明：本頁為 aogl.cn 書籤站整理的工具簡介，非廠商官方文檔；功能與價格以官網為準。

Cursor 是我維護本靜態倉庫用的 IDE：多語言 HTML、Node 構建腳本和 data/ 下的 JSON。放在工具目錄的「編程與 IDE」裡，因為改動最終要進 git——不是看新聞的地方。

在 aogl.cn 上的常見任務

  • 重構構建腳本（如 build-seo-locale-pages.mjs、hub 生成器）並保留倉庫上下文。
  • 生成多語言 HTML 殼，再手改 lang-* 塊。
  • 集中導航前全局搜索所有 site-nav 副本。
  • 在集成終端跑 npm run build-site 並逐文件修 lint。

怎樣不讓 Agent 改壞站

  1. 縮小範圍 — 一次一個腳本或一個 hub JSON，不順手格式化無關 HTML。
  2. 必跑構建 — build-hubs / build-articles 失敗則任務未完成。
  3. 不貼密鑰 — 公開腳本里的 AdSense ID 可以，私有 token 不行。
  4. 保留標記 — INDEX_ORIGINALS_AUTO_START 等註釋區間不能被覆蓋。

和 GitHub Copilot 的分工

目錄裡兩者都有。跨文件重構、以工作區為上下文的對話用 Cursor；單文件內補全用 Copilot 更輕。按任務粒度選，不站隊。

侷限

  • 不能代替閱讀 Claude、Gemini 或 API 定價的官網文檔。
  • 不會替我跑 GitHub Actions 定時任務。
  • 對外文章裡的生成文案發布前仍要人工核對事實與語氣。
