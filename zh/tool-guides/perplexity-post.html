Perplexity 用來問帶引用的一條窄問題——例如在 遊戲 Hub 看到標題後查「這篇稿是否提到某引擎」。與 Claude（長文）、Copilot（微軟系）互補。

適合本站維護的問題

  • 寫 Hub 文案前核對芯片公司縮寫。
  • 標題截斷時找投資者關係 canonical URL。
  • 改 tool-guides 前確認產品是否已更名。

不適合

  • 代寫 AdSense 文章——HTML 仍由站長寫。
  • 醫療 / 法律 / 投資決策。

流程

  1. 從下方官網進入。
  2. 粘貼不確定的標題或 URL。
  3. 點進一手來源，不以 Perplexity 本身當權威。
  4. 改 JSON 時更新 updated 日期。
