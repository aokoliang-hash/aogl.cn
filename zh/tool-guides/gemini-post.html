Gemini

對話與大模型

說明：本頁為 aogl.cn 書籤站整理的工具簡介，非廠商官方文檔；功能與價格以官網為準。

Gemini 是我常用的 Google 對話入口，主要做快速出圖找感覺和在進 data/articles/ 前頭腦風暴文案。與 Claude 並列在工具目錄，因為文本聊天重疊，但多模態默認和 Google 賬戶體系不同。

在本站的用法

  • 頭圖探索 — original/role-girl/、original/character/ 等目錄下的 PNG（水印僅作來源說明，不在此教去除）。
  • 配色核對 — 問「同一套衣服嗎」再定稿 contact sheet。
  • 標題備選 — changelog 用，三選一後手改。

實際流程

  1. 從下方按鈕進 gemini.google.com，用願意做實驗的 Google 賬戶。
  2. 寫清約束：畫幅、服裝錨點、不要 logo。
  3. 下載到 original/項目名/ 並帶日期命名；不覆蓋線上 Demo 主文件。
  4. 文章裡如實寫哪些進成片、哪些留在 look-dev。
  5. API / Vertex 細節請讀 Google 開發者文檔，不以本頁代替。

和 Claude 的分工

長英文改寫、細讀代碼多用 Claude；快速視覺和 Google 生態問題多用 Gemini。書籤裡兩個都保留，不假裝一個標籤萬能。

本站上的官方動態

DeepMind 發模型文時，同步摘要可能在 快訊，外鏈閱讀原文，不能替代發佈說明。

不要用來…

  • 把生成圖說成官方品牌素材。
  • 無人審核批量發文（與本站維護方式不符）。
  • 代替持證專業人士做判斷。
