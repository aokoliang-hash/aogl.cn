如何讀 App Store 遊戲榜（SEO 與選題）

  • 與 Today 編輯推薦區分 — Today 是人工策展故事線；帶序號的 grid 榜更接近「當前熱門下載/排行」快照。勿把編輯卡片標題當成排名。
  • 副標題 = 運營快照 — 「S43 賽季」「7 週年」「馬年寶藏」等是商店營銷文案，會隨活動更換；存檔 JSON 保留抓取時點。
  • App ID — 鏈到 apps.apple.com/cn/app/…/idXXXXXXXX；同名不同區服 ID 可能不同。
  • 與下方書籤對照 — 遊戲 Hub「全球平臺前十」書籤已對搜索引擎 noindex；本篇正文表格為可索引原創解讀。
  • 更新流程 — 編輯 JSON → npm run build-articles && npm run build-hubs。
