遊戲 Hub 快訊 × 生成式角色美術：個人工作流備忘

games.html Hot mix · 非官方美術抓取 · articles 歸檔

2026-06-18 · 本站原創

本文把 aogl.cn 上兩個常分開看的部分連起來：遊戲 Hub（Steam / 御三家 / 發行商第一方 RSS）與原創文章裡歸檔的生成式角色 look-dev。是個人週日流程——不是評測站、不是美術抓取教程，也與任何商店無隸屬關係。

週日循環（白話）

  1. 跑完 fetch-hub-news 後打開 games.html 看 Hot mix。
  2. 挑美術向標題（重製、角色預告、風格指南）；純服務器維護類通常止步於 Hub。
  3. 在 Midjourney 或 Gemini 問窄問題：只要「配色 + 剪影」，不「復刻這張官方 KV」。
  4. 探索圖存 original/項目名/ 並帶日期；偏離身份錨點的直接棄。
  5. 文件夾成熟後寫一篇誠實手記（HTML 設定表、contact sheet 或視頻）。

明確不做的事

  • 不抓商店美術 — KV 與縮略圖留在官方 CDN，本站不鏡像。
  • 無破解 / APK 索引 — 與遊戲 Hub 排除項一致。
  • 不寫「必玩十大」 — 本站流量策略是維護者歸檔，不是泛遊戲榜單。
  • 不堆提示詞教程 — 文章講取捨，不是 SaaS 說明書。

本站已有案例

  • 艾琳娜 · 海風之詩 — 海島祭司 HTML 設定表。
  • 艾琳娜配色與儀式 UI — 設定表維護手記。
  • 角色卡牌視覺練習 — 白裙 contact sheet。
  • 角色設計手記 — 四視圖與行走循環。

均非某商業遊戲的官方同人聲明，而是「跟著行業視覺做練習」的歸檔。

何時停在 RSS 就夠了

若標題只是停服維護，不必開生成工具、也不必新文章。遊戲頁作為閱讀軌已有價值；只有產出可檢查的 PNG / HTML / MP4 並寫好範圍段時，才新增 articles URL。

工具書籤

視頻：Runway；寫表：Cursor；長文：Claude；查陌生引擎名：Perplexity；全集：攻略索引。

發文章前自檢

  1. 首段寫明虛構 / 演練範圍，非真實房源或商品。
  2. 英文正文約 800 詞或同等深度，含圖 / 嵌入。
  3. original/ 文件名穩定且在 figcaption 中可查。
  4. 內鏈到相關 Demo（窗景合成、WebGL、其它角色線）。
  5. 改資產則更新 dateModified 與 changelog。

為何放在 articles 而非 games.html

Hub 頁保持短導語 + 外鏈；長流程會稀釋定位並帶來「薄頁」風險。可教敘事放文章，games 頁繼續當週日標題條。
