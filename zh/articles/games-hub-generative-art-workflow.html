遊戲 Hub 快訊 × 生成式角色美術：個人工作流備忘

games.html Hot mix · 非官方美術抓取 · articles 歸檔

2026-06-18 · 本站原創

本文把 aogl.cn 上兩個常分開看的部分連起來：遊戲 Hub（Steam / 御三家 / 發行商第一方 RSS）與原創文章裡歸檔的生成式角色 look-dev。是個人週日流程——不是評測站、不是美術抓取教程，也與任何商店無隸屬關係。

週日循環（白話）

  1. 跑完 npm run fetch-hub-news 後打開 games.html 看 Hot mix。
  2. 挑美術向標題（重製、角色預告、風格指南）；純服務器維護類通常止步於 Hub。
  3. 在 Midjourney 或 Gemini 問窄問題：只要「配色 + 剪影」，不「復刻這張官方 KV」。
  4. 探索圖存 original/<項目名>/ 並帶日期；偏離身份錨點的直接棄。
  5. 文件夾成熟後寫一篇誠實手記（HTML 設定表、contact sheet 或視頻）——案例如下。

明確不做的事

  • 不抓商店美術 — KV 與縮略圖留在官方 CDN，本站不鏡像。
  • 無破解 / APK 索引 — 與遊戲 Hub 排除項一致。
  • 不寫「必玩十大」 — 本站流量策略是維護者歸檔，不是泛遊戲榜單。
  • 不堆提示詞教程 — 文章講取捨，不是 SaaS 說明書。

本站已有案例

下列文件夾從「標題啟發的 look-dev」長成了獨立 URL：

  • 艾琳娜 · 海風之詩 — 海島祭司 HTML 設定表與探索圖。
  • 艾琳娜配色與儀式 UI — 同一設定表的維護手記。
  • 角色卡牌視覺練習 — 白裙 contact sheet 線。
  • 角色設計手記 — 四視圖與行走循環紀律。

均非某商業遊戲的官方同人聲明，而是「跟著行業視覺做練習」的歸檔。

何時停在 RSS 就夠了

若標題只是停服維護，不必開生成工具、也不必新文章。遊戲頁作為閱讀軌已有價值；只有產出可檢查的 PNG / HTML / MP4 並寫好範圍段時，才新增 articles URL。

工具書籤

視頻 look-dev：Runway 備忘。寫設定表：Cursor。長文潤色：Claude。新聞稿提到陌生引擎時查證：Perplexity。全集：攻略索引。

發文章前自檢

  1. 首段寫明虛構 / 演練範圍，非真實房源或商品。
  2. 英文正文約 800 詞或同等深度，含圖 / 嵌入。
  3. original/ 文件名穩定且在 figcaption 中可查。
  4. 內鏈到相關 Demo（窗景合成、WebGL、其它角色線）。
  5. 改資產則更新 dateModified 與給人看的 changelog。

為何放在 articles 而非 games.html

Hub 頁保持短導語 + 外鏈；長流程會稀釋定位並帶來「薄頁」風險。可教敘事放文章，games 頁繼續當週日標題條。

Hot mix 裡我真正掃什麼

不是每條 RSS 都值得開生成會話。我把這些當綠燈：角色重設博客、畫集預告、「製作花絮」訪談、風格化預告片，或帶 UI 線稿的補丁說明。紅燈一律跳過：停服維護、純反作弊公告、電競對陣結果、沒有畫面的折扣百分比。紀律無聊，但能防止 original/ 堆滿永遠不會寫成文章的文件夾。

標題含糊——比如只有「visual update」沒有截圖——我會點一次外鏈。若發行商頁純文字，就停。我不從 slug 猜美術方向。

original/ 下的文件夾命名

每條成熟線自有目錄：original/game-girl/、original/role-girl/、original/character/。目錄內文件名按時間：探索圖用 ChatGPT Image YYYY…png，一張權威三視圖（ChatGPT-Image2.png 或 card.png），可選 HTML 設定表。絕不把同一文件夾複用給另一張臉——那是磁盤與搜索摘要裡卡牌線撞車的根源。

文章尚未存在時，文件夾至少要有：(1) 一張尺子圖或設定表；(2) 三張能看出決策的帶日期探索圖；(3) 本地 README 裡一段範圍說明（文章上線前不公開）。

上線前砍掉的文件夾

2026 年有兩次實驗從未變成 URL：一套賽博跑者剪影，三幀後漂進受版權保護的標誌形狀；一次「奇幻祭司」通路，並排對照後斗篷剪裁太像某商業遊戲。早刪比寫一篇承認模仿更便宜。那些 PNG 從未進 git。

和 tech.html 的對照

科技 Hub 喂芯片與模型標題。我讀它是為了政策語境——出口規則、API 定價——但很少從那裡派生角色文件夾。當科技 RSS 與遊戲 RSS 重疊（主機 SoC 新聞）時，我心裡歸到科技；只有它改變了我用的工具（例如本地推理加速影響批量導出）才在文章裡交叉鏈接。

週日時間預算

大約九十分鐘：二十分鐘掃 RSS，四十分鐘一輪窄提示詞生成，二十分鐘歸檔改名，十分鐘決定「寫不寫文章」。若這一輪沒有可留檔品質，我仍提交 Hub JSON 更新，但跳過生成——不為內疚硬湊內容。

我刻意寫在明處的法律衛生

商店 KV 留在官方 CDN。我不拿抓來的 KV 訓練，不為發佈去水印，也不把練習文件夾標成官方同人。文章重複這條邊界，好讓 AdSense 審閱看到意圖：這是維護者歸檔，不是盜版站或扒圖站。

中文加厚：週日工作流與案例鏈

Games Hub 不是外鏈牆的另一張皮，而是把 Elena 設定表、角色卡牌、四視圖行走等已完成案例串成可重複的一週節奏：選題 → 出圖 → 進 original/ → 寫中英手記 → 掛 Hub。工具名可以變，文件夾命名與「先歸檔再寫文」的順序不能變，否則站點會重新滑向書籤目錄。

Hot-mix 紅綠燈只作內部提示：綠表示可進主索引的厚 Demo，紅表示仍像導購或榜單的素材。寫這篇的目的，是讓審核員看到作者如何自我約束內容類型，而不是看到又一個「AI 工具大全」。
