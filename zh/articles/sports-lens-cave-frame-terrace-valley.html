洞穴框景 × 梯田櫻谷：長焦窗框風光合成手記

jib1od · 1frod · video.mp4 · 框中框構圖

2026-06-22 · 本站原創

這是 aogl.cn 歸檔的第 16 篇原創手記，素材在 original/sports-lens/。項目代號「sports-lens」指的是長焦/窗框式取景練習——用洞穴口當天然暗角畫框，框住梯田、櫻樹、河流與遠山霧帶，再導出 MP4 看「框中框」在運動時是否仍成立。不是某省某縣旅遊宣傳，也不標註真實 GPS；只記錄文件名、構圖決策與和站內其他「窗框線」文章的差異。

標題與圖注裡會出現真實檢索詞：cave frame landscape、terrace rice fields、cherry blossom valley、natural window composition、frame-in-frame video——均對應磁盤上的畫面，不是無關熱詞堆砌。

為什麼做「洞穴框景」而不是全畫幅風景

站內已有 高鐵車窗、客機舷窗雲海 與 公寓 360° 全景。本篇補的是有機暗框：窗框不是矩形玻璃，而是不規則巖洞輪廓，前景幾乎全黑，觀眾先讀到「我在看一個被限定的視野」，再進入谷地敘事。心理學上，這種窺視/發現秘境的構圖比平鋪全景多一層「藏」與「揭」。

我把前景洞穴地面留了一小叢粉白野花——不是寫實植物誌，而是給絕對暗部一個尺度錨點：沒有它，巖框會像純 vignette 濾鏡；有它，人眼會接受「相機在洞內、主體在洞外」的空間分層。

定稿靜幀 jib1od：封面為什麼選它

三張 PNG 裡，jib1od 的框緣對比最強：頂部垂下的藤條與巖齒把天空切成不規則拱門，中間谷地亮度最高，遠峰與低雲形成第二條水平線。1frod 系列在櫻色偏品紅或霧太厚時我會保留為本地對照，但不作輪播封面——縮略圖需要 16:9 下一眼讀出「框+谷」，而不是「一片粉色樹林」。

兩張 1frod 探索幀：我在改什麼

生成式出圖常見問題是框緣漂移：洞口的岩石厚度一變，整個透視故事就崩。1frod 與 1frod1 是我同 prompt 方向下的兩次保留，用來對比：

  • 1frod — 框緣更寬、暗部更佔畫面；適合測試「暗角是否壓過主體」
  • 1frod1 — 河谷水面更亮、櫻樹更密；適合測試「高光會不會假到像 HDR 濾鏡」

兩者都沒有替換 jib1od 成為 hero，因為文章需要一張最穩的默認敘事幀；探索幀只服務本地 before/after，不增加訪客認知負擔。

谷地元素：梯田、櫻樹、河、霧

畫面中段是階梯梯田與水面反光——我刻意不寫成「元陽」「龍脊」等真實地名，因為文件並未綁定測繪數據。櫻樹成片是為了提供季節色塊：在縮略圖裡與綠色梯田形成互補，讓「框中框」內部仍有第二層視覺節奏。

遠峰與低雲（或晨霧）負責縱深：如果只有中景梯田，洞穴框會顯得像貼圖；有了第三條大氣透視線，觀眾才會把谷地讀成「可走進去的世界」，而不是一張平面插畫。

video.mp4 與 video-2.mp4

靜幀可以靠構圖騙人，視頻會暴露框緣是否閃爍、櫻樹是否有不合邏輯的抖動、雲霧是否像循環貼圖。主成片 video.mp4 是 2026-06-22 重新導出的版本；video-2.mp4 保留較早一輪參數，方便我對照「暗部是否發灰」「河面高光是否過曝」。

和站內其他「窗框線」怎麼分工

  • 高鐵車窗 — 人造矩形窗 + 運動模糊外景
  • 舷窗雲海 — 橢圓舷窗 + 高空平流層
  • sports-lens — 有機巖框 + 地面谷地（本頁）
  • 穿越視差手機 — 矩形屏幕框 + 分層 PNG

四條線共用同一套驗收問題：框是否先於場景被讀懂？換場景後框是否仍可信？ 答案為否的素材不會進 git。

工具與邊界

靜幀來自 Gemini 出圖探索；文件名保留 Gemini_Generated_Image_… 以便和 girl1 九格、role-girl 卡牌 一樣可追溯批次。我不在文中複述 vendor prompt，也不教「一鍵生成 Shangri-La」。若你 fork 做紀實攝影，應替換為可核實的拍攝地點與 EXIF，而不是沿用本文件夾的虛構谷地。

出圖後我只在本地做裁剪與視頻導出；HTML 文章負責誠實說明範圍。這與 AdSense 階段「articles 為主內容」的策略一致：一篇 URL 對應一個可檢查的 original/ 目錄。

維護約定

  1. 換 hero PNG → 重跑 npm run generate-article-covers 並更新 dateModified。
  2. 新增探索幀 → 只加入 gallery，不自動替換 hero，除非框緣故事更清楚。
  3. 不在 hub-links 或 briefs 重複發同一組圖；長文只駐留 articles/。

下一篇若繼續「框景線」，可能是廢棄塔樓窗洞或橋洞框架——仍須先有過關靜幀與 MP4，再寫 scope 段落；不會為湊 17 篇而複製本頁結構。
