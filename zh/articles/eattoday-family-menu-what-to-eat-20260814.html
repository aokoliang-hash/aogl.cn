EatToday 今天吃什麼：家庭點菜 × 今日菜單分享手記

本人開發 · App：http://eattoday.aogl.cn/ · 家庭房間 · 三餐點菜

2026-08-14 · 本站原創

這是 aogl.cn 上的一篇個人原創開發手記，素材全部來自 original/eattoday/（2026-08-14 歸檔）。EatToday（今天吃什麼）是本人開發的 App（頁腳署名 © kolang），入口：http://eattoday.aogl.cn/——把家裡每晚「今天吃什麼 / 誰做飯」的決策成本，壓成一條可分享的家庭今日菜單。一人或多人點菜，做飯的人打開當日清單，按食材、步驟和可選視頻外鏈下鍋。本文不是轉載軟文，而是作者按真實截圖拆解：點菜頁、三餐槽位、菜譜詳情、空狀態引導、家庭房間邀請碼，方便檢索「家庭今天吃什麼 App」「共享家常菜菜單」「免註冊家庭點菜」等長尾詞。

產品定位：壓縮家庭決策成本

多數「菜譜站」優化瀏覽；EatToday 優化另一種失敗模式：家裡其實會做菜，但今晚沒人願意拍板。README 寫得很直接——用三步砍掉「吃什麼 / 誰做」的扯皮：

  1. 點菜 — 按分類或搜索家常菜，加入早/午/晚。
  2. 今日菜單 — 生成帶日期的清單，做飯的人一眼能照單執行。
  3. 分享 — 把房間鏈接或邀請碼發給灶臺前的人。

它更接近輕量家庭協作工具，而不是 SEO 菜譜農場。只有美圖沒有「今日清單」，每晚還得重談；只有群聊沒有三餐槽位，消息一刷就丟。EatToday 用頂部雙頁籤釘住兩端：點菜與今天吃。

角色：點菜的人 / 做飯的人 / 管理員

  • 點菜的人 — 要快瀏覽、加入今日、能分享。
  • 做飯的人 — 要今日清單、食材步驟/視頻、做中/已做狀態。
  • 管理員 — 維護分類、菜式、食材、步驟與視頻外鏈。

這些角色來自 README.txt，不是編出來的人設。產品刻意支持暱稱參與、弱註冊：創建或加入家庭房間即可點菜。用家庭真實場景換掉企業式登錄牆——爺爺奶奶和小孩最容易死在「先填郵箱」那一步。

點菜頁：搜索、分類、三餐槽位

「點菜」頁在頁簽下有三枚餐次膠囊：早餐 / 午餐 / 晚餐。當前餐次會改寫每張菜卡按鈕文案（如「加入早餐」）。搜索框佔位：「搜菜名，比如番茄炒蛋」——番茄炒蛋既是品牌菜名，也是搜索示例，語氣一致。分類芯片含全部、家常炒菜、湯羹、蒸煮燉、主食麵點、涼菜小吃、下飯硬菜。列表可「加載更多（已顯 24/80）」，避免首屏一次塞八十張卡。

歸檔可見菜名包括土豆燒排骨、魚香茄子、蒜蓉烤排骨、紅燒雞翅根、啤酒鴨、虎皮青椒、涼拌海帶絲、皮蛋豆腐等。正文重複這些實體是有意為之：具體家常菜長尾詞可以落到「既有產品說明又有菜單工具」的頁面，而不是薄關鍵詞表。

菜譜詳情：時長、視頻，再加入某餐

打開「土豆燒排骨」可見標題「菜譜詳情」、主圖、時長芯片「大約 60 分鐘」、視頻教程卡，以及與當前餐次一致的橙色主按鈕「加入早餐」。做飯路徑很清楚：先看懂怎麼做，再提交到今日看板。視頻是可選教學輔助，產品核心仍是共享菜單契約，而不是播放量。

今天吃：用空狀態教迴路

示例「今天吃」頁顯示 敖家 · 2026-08-14，右側紅色「分享給家人」。早/午/晚計數為 0。空卡片不是空白——它在教：「選幾道家常菜，做飯的人一眼就知道做什麼」，並提供「去點早餐的菜」。好的空狀態等於嵌在 UI 裡的產品文檔。對 AdSense 與人工審核也有用：截圖證明這是設計過的協作流程，不是洗稿菜譜堆。

有菜之後，做飯的人應按用戶故事看到分餐清單，並把狀態改為做中 / 已做。狀態閉環解決協調問題：點菜的人少問「好了沒」，做飯的人少猜「哪條微信才是最終菜單」。

家庭房間：創建、邀請、加入

沒有房間時進入房間頁：「還沒有家庭房間」，可創建房間或輸入邀請碼加入。加入可填暱稱（佔位「吃貨」）與邀請碼或粘貼分享鏈接。這是 EatToday 相對個人備忘 App 的多人邊界。同站產品 WordPet（wordpet.aogl.cn）解決單人學習習慣；EatToday 解決圍繞一口灶的多人協調習慣。

把交互產品放在兄弟域名 eattoday.aogl.cn，與 aogl.cn 靜態編輯站分界：長文 SEO 在 aogl.cn 首屏 HTML；點菜狀態與房間 cookie 留在獨立宿主。線上演示請優先使用當前可用的 http:// 入口，文案不虛構 HTTPS 可用性。

不願稀釋的用戶故事

  1. 作為家人，我可用暱稱創建或加入房間並開始點菜，不必長註冊。
  2. 作為點菜的人，我可按分類/搜索找菜，看食材步驟，加入今日某餐。
  3. 作為點菜的人，我可複製房間鏈接或邀請碼給做飯的人。
  4. 作為做飯的人，我可在做飯模式看今日列表並標記做中/已做。
  5. 作為管理員，我可上下架菜譜、編輯教程與視頻鏈接。

趁 UI 還熱馬上寫手記，才能誠實：照抄界面文案（點菜、今天吃、加入午餐、分享給家人），不承諾未截到的路線圖，也不把產品寫成營養/醫療建議。它是決策與協調工具。

與 aogl.cn 並排發佈的工作流備忘

截圖用時間戳文件名歸檔，方便審核核對來源。封面仍走 npm run generate-article-covers，生成 1200×675 WebP，不用庫存圖。中文服務「今天吃什麼」地域意圖；英文服務 family meal planner / shared menu 等國際檢索。短語種（日韓法俄阿）保持短文——中英厚文才是送審重量。

相對本站已 noindex 的榜單存檔，EatToday 應進可索引主內容：本人產品、本人截圖、第一人稱制作說明，與 WordPet 同屬「作者軟件 + UI 證據」這一檔。

無障礙與 SEO 清單

  • alt 寫可見 UI 實體（餐次、菜名、按鈕），禁止「圖片1」。
  • 正文重複 EatToday、今天吃什麼、App 地址 http://eattoday.aogl.cn/、點菜、今天吃、家庭房間、邀請碼、土豆燒排骨、番茄炒蛋。
  • 外鏈加 rel="noopener noreferrer"；完整敘事放在首屏 HTML。
  • 引用空狀態文案，讓爬蟲在零點菜演示時也能理解迴路。
