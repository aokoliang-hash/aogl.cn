WordPet 背單詞養寵物：石猿進化 × 教材同步詞書手記

本人開發 · App：https://wordpet.aogl.cn/ · 每日打卡 · 教材詞書

2026-07-15 · 本站原創

這是 aogl.cn 上的一篇個人原創開發手記，素材全部來自 original/wordpet-app/（2026-07-15 歸檔）。WordPet 是本人開發的 App（頁腳署名 © 2026 kolang），入口：https://wordpet.aogl.cn/——把教材同步背單詞與寵物養成綁在同一套習慣迴路裡的移動端 App（Web）。口號寫得很直白：每日背單詞，餵養你的石猿。本文不是轉載軟文，而是作者按自己產品的真實截圖拆解：註冊領養、詞書選擇、認識/不認識閃卡、寵物對話語音、SSR 蛋期出戰與寵物庫稀有度，方便檢索「教材同步英語單詞 App」「背單詞養寵物」等長尾詞。

產品定位：習慣迴路，而不是再堆一套單詞表

市面上不缺「認識 / 不認識」閃卡。WordPet 的差異在於把學習結果喂進可見的養成反饋：背詞 → 獲得經驗 → 寵物進化 / 換裝出戰。登錄頁把路徑壓成五步：

  1. 註冊登錄 — 建立可續期的賬號，而不是一次性訪客狀態。
  2. 領養寵物 — 情感錨點（石猿、哪吒等）先於長列表詞書。
  3. 每日打卡 — 用日期節律把詞彙量變成習慣，而不是一次背完三百詞的突擊。
  4. 獲得經驗 — 把「認識」反饋量化成 XP，對接寵物等級與戰力。
  5. 進化成長 — 靈火蛋期、金階、星級等視覺層級，讓進步可感知。

從用戶心理上說，這是外在誘餌（萌寵）服務內在目標（教材詞彙）：家長關心同步詞書，孩子關心出戰與對話。產品若只做其一，要麼變成枯燥詞表，要麼變成與學習脫鉤的扭蛋。WordPet 把兩者綁在同一底欄：首頁 / 學習 / 寵物 / 我的。

詞書學習：教材對齊比「通用詞庫」更重要

「詞書學習」頁頂部釘住主詞書示例：滬教版 · 五年級上冊。分類標籤含教材同步（默認）、通用年級、其它；教材版本橫向滾動可見人教 PEP（2026 秋）、外研版 NEW、滬教版 NEW；學段可在小學 / 初中間切換。列表卡片展示單元數、進度條（如 13%、4%）與「設為主詞書（用於每日打卡）」按鈕。

對小學英語而言，「進度」若不以課本單元為軸，打卡就會和課堂考試錯位。我刻意在正文重複人教 PEP、滬教版、外研版、五年級上冊、三年級上冊等實體名，方便家長用教材名稱檢索。把某一冊設為主詞書後，「今日單詞」來源條會顯示同一詞源（見下），保證打卡隊列與主詞書一致。

今日單詞：最小阻力閃卡

「今日單詞」界面示例中，進度為 1 / 10，詞源為滬教版五年級上冊。中心卡片展示例詞 pilot、/ˈpaɪlət/、釋義「n. 飛行員」與例句 The pilot flies the plane.，旁有發音按鈕。底部雙按鈕為不認識 ✕ / 認識 ✓——經典間隔複習入口，刻意做得極大，適配拇指區。

設計取捨上，我偏好當天量小、反饋清晰（10 詞量級），而不是一次 100 詞的勸退隊列。經驗值應綁定「認識」與糾錯後再認識，而不是單純翻頁；否則寵物 XP 會與真實記憶脫節。反饋入口「意見反饋」放在閃卡頁底部，方便學生報錯音標或例句。

我的寵物：哪吒靈火蛋與出戰

「我的寵物」頂部輪播可見哪吒、石猿、墨韻龍等。示例中哪吒為出戰 SSR：靈火蛋期、Lv.4、金-1、戰力 95、經驗 660/1000，文案「靈火裂蛋，熾熱氣息湧動」。卵殼裂紋與火焰粒子把「還在養成」寫成畫面，而不是一張已定型立繪——這對「進化可期待」至關重要。

寵物命名混合神話 IP 感（哪吒、石猿、墨韻龍）與學習語義（見寵物庫中的單詞貓、知識犬），讓收藏既好玩又可記。戰力與等級是給孩子看的「分數板」；真實學習仍應回看詞書進度條，避免只追求扭蛋。

寵物對話：口語練習的輕入口

「寵物對話」把出戰寵放在中間，哪吒卵上方氣泡出現中英混合提示（例：Apple is a sweet name! 並提到敖丙與明日背單詞）。底部為按住說話，鬆開發送的麥克風主按鈕，旁有鍵盤與揚聲器等輔助。這是把語音輸入嵌進養成場景，而不是另開一個冷冰冰的口語考場頁。

實現上需注意：弱網、麥克風權限拒絕、兒童隱私與內容審核。產品文案宜保持短、鼓勵、可英中混排；長作文題不適合塞進氣泡。對 SEO，本文強調「寵物對話」「按住說話」等界面詞，覆蓋語音學英語相關檢索。

寵物庫：稀有度與「去召喚 / 設為出戰」

「寵物庫」網格展示白蛇、麒麟、白澤、玉兔、朏朏、石猿、單詞貓、知識犬、老虎等，稀有度標籤含 SSR / SR / S / A。未擁有顯示「去召喚」，已擁有顯示「設為出戰」。石猿標為 SSR「已擁有」，與品牌吉祥物呼應。

收集系統的健康邊界：召喚消耗不應壓過每日背詞；否則產品會滑向付費扭蛋敘事。WordPet 的主路徑仍應是主詞書打卡 → XP → 進化，召喚是支線皮膚。寫作本稿時，我把「單詞貓 / 知識犬」當作可檢索的趣味關鍵詞，提醒搜索引擎這是學習向養成，不是泛二次元抽卡站。

信息架構小結（四欄底導航）

  • 首頁 — 今日任務與入口聚合。
  • 學習 — 詞書 + 今日單詞（教材對齊的主戰場）。
  • 寵物 — 出戰、對話、圖鑑（情感與留存）。
  • 我的 — 賬號與設置。

該結構對小學生拇指操作友好，也方便家長一眼找到「換詞書」。與本站其它 Demo（角色轉身、WebGL 地球）不同，本篇更貼近 EdTech / 小學英語 / 習慣養成 關鍵詞簇，適合作為 AdSense 審核時的「真實產品原創說明」樣本之一。
