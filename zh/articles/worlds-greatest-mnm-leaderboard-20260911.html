世界之最 mnm：付費上榜 × 3D 宇宙榜單手記

本人開發 · App：https://mnm.aogl.cn/ · 話題榜 · 國家板 · 出價上榜

2026-09-11 · 本站原創

這是 aogl.cn 上的本人一手產品手記。截圖歸檔在 original/worlds-greatest/（2026-09-11）。「世界之最」是我自己開發的應用（頁腳 © kolang）。入口：https://mnm.aogl.cn/——公開的付費展示榜：名次等於出價，話題與國家是一等公民篩選軸，右側（或移動端全屏）用 3D 宇宙場景（星系 → 太陽系 → 地球）當舞臺。本文不是聯盟軟文，而是對照本人 UI 截圖寫清楚：榜單列表、話題標籤、國家條、出價彈層、個人主頁卡、看榜/我要上榜，方便檢索「付費上榜」「話題國家榜」「3D 地球上榜」「mnm.aogl.cn 世界之最」等意圖。

定位：名次就是出價，沒有別的

多數社交「排行榜」把名次歸因於點贊、投票或黑盒算法。「世界之最」在規則裡寫得很直白：公開的付費上榜；出價更高名次更高；同價以先支付者優先。最低出價 ★1；要佔 #1，至少比當前第一多 ★1。已上榜名稱可登錄後只補差價爬升。這更接近透明的展示位市場，而不是爬取「世界富豪」新聞的內容農場。

文案對法律邊界同樣剋制：付錢買的是展示位；不是抽獎、不是賭博；款項一般不退；違規內容可下架不退款。寫 SEO / AdSense 手記時要守住這句話：本文描述的是我做的自助上榜界面，不要發明彩票話術。動態裡的金色數額是當次支付，不是神秘累計總分。

話題與國家：兩條正交軸

榜單上方是話題芯片，例如 #Richest / #最有錢、#Startups，以及中文挑戰話題如 #比最牛的網站公司、#比世界最帥，另有 + New topic 與「更多話題」抽屜。列表空時可以出價創建話題——分類是用戶長出來的，不是凍死的 CMS 樹。話題之下是國家條：全部、中國、美國、日本、韓國、阿聯酋、瑞典、新加坡、瑞士、越南、加拿大、澳大利亞、印度、中國香港等。左側列表只供瀏覽；真正上榜國家來自定位面板（自動檢測 + 手動改國家/城市）。

把話題和國家拆開，實體更乾淨：新加坡創業者與深圳玩笑號不必擠在同一無差別滾動條裡。「今日」與「All-time」再切一刀：今日統計近 24 小時支付；All-time 保留長榜。頂欄的在榜人數、累計出價是社會證明，但不聲稱第三方財富核驗。

出價上榜：彈層鏈路

主 CTA 在「Get listed / 我要上榜」與行內「Overtake / 搶佔」「Pass」之間切換。我落地的流程刻意分段：

  1. What to rank — 展示名；可選簡介或 URL。
  2. Confirm this bid — 預估名次、應付金額、話題、名稱、國家、榜單合計；需勾選同意條款。
  3. Choose payment — 星數、幣種、支付方式（生產環境 Stripe/合作方；開發可 Mock）。
  4. Secure checkout — 彈窗結賬，支持「我已支付」回跳。

首次上榜可不登錄；給已有名稱加價要登錄。衝動上榜應「一次支付就結束」，保衛名稱則需要賬號，以免別人靜默搶走展示字符串。分享面板覆蓋微信、微博、QQ、X、Facebook、WhatsApp、Telegram、LinkedIn，以及下圖與複製鏈接——分發是產品能力，不是事後插件。

個人主頁與最新動態

點開一行進入個人主頁：名次花環、頭像首字母、展示名、國旗、星數、可選簡介/URL、上榜日期，以及訪問主頁、分享、搶佔他的位置。簡介是自由文本——有人開玩笑，有人貼產品鏈，有人只有默認「Listed 日期」。底部動態條解釋誰超過了誰、誰付了 ★N 進入哪一名。把動態做成支付與超越的流水，強化「透明市場」隱喻，也給首頁動感，而不偽造點贊類指標。

3D 舞臺：星系 → 太陽系 → 地球

右側（或移動端畫布）不只是裝飾。截圖裡能看到三層嵌套：

  • 星系 / 宇宙 — 可拖拽環視；提示「拖拽環視 · 點擊太陽系進入」。
  • 太陽系 — 太陽與行星，帶縮放/復位控件。
  • 地球 — 可旋轉地球與釘點；「看榜」「我要上榜」；提示「拖拽旋轉 · 點「看榜 / 我要上榜」 · 返回太陽系」。

移動端雙 CTA 很清楚：深色看榜打開榜；金色我要上榜開始出價。3D 層讓產品像「地方」而不像表格。對 SEO 而言，榜單機制仍必須用 HTML 講清楚——只靠 WebGL 對爬蟲和關閉重腳本的審核員都太弱。

為何放在 mnm.aogl.cn 而不是主站

交互應用跑在 mnm.aogl.cn，長文留在 aogl.cn，可以把 Cookie、支付回跳、WebGL 包與編輯部靜態站隔離。WordPet（wordpet.aogl.cn）、EatToday（eattoday.aogl.cn）同一套路：產品在子域，製作手記在多語言歸檔。時間戳文件名放進 original/worlds-greatest/，方便審核追溯。封面仍走 npm run generate-article-covers，Open Graph 用 WebP，不靠圖庫。

相對本站那些 Steam / Amazon 類榜單存檔（保持 noindex），「世界之最」屬於可索引主文：原創產品、原創截圖、第一人稱過程。與 WordPet、EatToday 同類——作者自建軟件 + UI 證據——儘管產品形態本身是榜單界面。

寫作時不願稀釋的約束

  1. UI 文案照抄：世界之最、我要上榜、看榜、All-time、Today、Pass、Overtake、Bid to rank。
  2. 不聲稱第三方財富核驗；星數是出價，不是審計淨資產。
  3. 不把產品寫成賭博；沿用條款裡的「展示位」表述。
  4. 定位可改——上榜前必須能糾正國家/城市。
  5. Mock 支付只用於開發；生產支付方式需運營方啟用。

趁 UI 還熱寫完，才能誠實：在榜人數與 #1 名字按小時變；本文凍結的是 2026-09-11 這一組截圖。中文服務「世界之最 / 上榜」意圖；英文服務 pay-to-rank / topic leaderboard / 3D earth board。短語言包（日/韓/法/俄/阿）故意短——過審重量在中英厚文。

無障礙與 SEO 清單

  • alt 寫清可見實體（話題芯片、國旗、CTA、星系/地球），禁止「圖片 1」。
  • 正文重複：世界之最、Worlds Greatest、https://mnm.aogl.cn/、出價上榜、All-time、Today、話題、國家板、我要上榜、看榜。
  • 產品外鏈 rel="noopener noreferrer"；完整敘事在首屏 HTML。
  • 用正文解釋最低出價、差價加價、不可退展示位，避免必須點開彈層才懂產品。

邊界

這些截圖記錄的是本人開發的「世界之最」（© kolang）——個人產品與 UI 歸檔。在榜名單、星數、話題名隨部署與拍攝時間變化。本文不聲稱真實世界財富核驗、投資建議或彩票獎金。未成年人參與支付流程需監護人陪同。
