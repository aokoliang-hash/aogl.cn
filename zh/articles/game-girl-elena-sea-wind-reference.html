海島祭司艾琳娜：海風之詩設定表與生成探索

elena_character_sheet.html · ChatGPT-Image2 三視圖源 · 5/18–5/20 探索圖

2026-06-03 · 本站原創

這是 aogl.cn 上的第 13 篇原創歸檔，素材全部來自 original/game-girl/。和 白裙 role-girl 卡牌線、girl1 米色針織線 並列：本篇走的是海島幻想 + 祭司職業——中文名「艾琳娜」，稱號「海風之詩」，22 歲、168 cm，所屬「碧海群島·潮音祭司團」。目標不是交付可上線的遊戲角色包，而是把生成式出圖收束成一張可讀的設定表 HTML、一張三視圖源圖、若干日期命名的探索 PNG，並用這篇手記說明「留下什麼、為什麼」。這不是工具教程，也不教你去某個 App 裡複製提示詞。

我為什麼選「祭司 + 沙灘紗裙」而不是再畫一條現代都市線

本站已有城市窗邊針織、白蕾絲卡牌、動畫向四視圖行走——再堆一條「普通 T 恤少女」只會和 girl1 搶識別度。海島線的好處是輪廓與配色自帶邊界：象牙白抹胸、半透明紗裙、金鍊腰飾、潮沙法杖、梔子花環，在縮略圖裡仍然可讀。我把世界觀寫成「碧海群島」的輕幻想，不是硬科幻，這樣我在 HTML 裡寫色板和世界設定段落時，不會和真實宗教符號攪在一起——頁面裡用的是虛構組織「潮音祭司團」與海洋女神信仰，明確標註為個人練習。

定稿前的最大風險是「每張都像泳裝廣告」。我在設定表裡強制保留168 cm 身高標尺、三視圖裁切框、五枚表情圓片——它們逼我在改 Prompt 時優先問「體態有沒有漂」，而不是「皮膚高光夠不夠豔」。

核心文件：elena_character_sheet.html

文件夾裡唯一的手寫代碼是這個 1600×900 的靜態頁：左側信息欄（姓名、稱號、武器、元素、性格），中間三視圖（正 / 側 / 背，共用 ChatGPT-Image2.png 的不同裁切），右側表情五態、服裝 SVG 分解、色板與世界觀短文。字體用 Noto Serif SC + Cinzel，背景是淺藍網格水印——整體偏「官方設定集」排版，但頁腳仍寫 Official Character Design · Confidential 只是視覺語氣，不代表任何商業項目。

三視圖不是三張獨立 PNG，而是一張寬圖裡用 CSS object-position 切出 front / side / back。這樣做的好處是：換源圖時只替換 ChatGPT-Image2.png 一處；壞處是側背角度完全依賴源圖裡是否真有足夠像素——若源圖只有正面，側面框裡會出現拉伸感，我會在探索階段直接判失敗。

源圖 ChatGPT-Image2.png：一張圖扛三視圖

這是 5 月 18–20 日多輪出圖裡最終用來進設定表的那張寬構圖。我要求模型在同一張裡給出可裁切的全身正面與足夠寬的左右留白，以便側面與背面框不至於空。下面放原圖全幅，方便你對照 HTML 裡的裁切邏輯。

按日期命名的探索圖：我在改什麼

ChatGPT Image 2026年5月18日 … 到 5月20日 … 共七張 PNG，不是「抽卡湊數」，而是分階段驗收：

  • 5/18 早期 — 先鎖臉與髮型（長直、淺棕、劉海是否擋眼），服裝允許臨時簡化，只看五官一致性。
  • 5/19 中期 — 加金鍊、臂環、法杖輪廓；檢查紗裙層數是否可讀（至少兩層透明疊壓）。
  • 5/20 後期 — 背景改為淺海或白棚，測試導出後縮略圖是否仍像同一個人；失敗幀直接刪，不進入 HTML。

七張裡我保留差異最明顯的六張做對比牆；若某張與 ChatGPT-Image2.png 五官衝突，它只留在硬盤上當「反面教材」，不上正文。

設定表裡的「硬信息」我怎麼用

左欄表格不是裝飾。身高 168 cm、元素「水」、武器「潮沙法杖」會反過來約束後續出圖：若某張探索圖裡出現火焰特效或重甲，我會標為離題。色板分主色（象牙白 / 天光藍 / 海洋藍 / 深海藍）、輔色（沙灘米 / 暖沙金）、點綴色（法杖金 / 花冠綠 / 寶石藍）——改 Prompt 時我只允許在同一行色板裡微調飽和度，不允許突然換成霓虹紫發。

世界觀段落寫的是「碧海群島」與「潮沙之力」——給以後若寫短篇或關卡文案留鉤子，但本篇不附遊戲機制數值，避免讀者以為這是即將發售的 IP。

表情五態：CSS 濾鏡而不是五張臉

設定表右側五個圓片共用同一張臉，用 filter:saturate/brightness/hue-rotate 做「溫柔 / 微笑 / 沉思 / 堅定 / 喜悅」的近似。這是刻意的工程選擇：我尚未畫出五張獨立表情稿，但需要在排版上佔住位置，提醒未來補圖。若你要復刻這套流程，建議最終仍用五張獨立 crop 替換濾鏡版——濾鏡版只適合作個人草稿，不適合對外交付。

我刻意沒做的事

本文件夾沒有骨骼綁定、Spine 圖集、UE MetaHuman、或任何商店可下載的 package.json。沒有對外宣稱的 Gacha 卡面或 Live2D 工程。平臺水印若出現在某張探索 PNG 上，我只作來源記錄，不在此教去水印或批量爬圖。HTML 設定表也沒有接後端——它就是靜態文件，方便我整頁 iframe 進文章，像 行走循環頁 嵌入 walk.html 一樣。

和本站其他角色頁怎麼分工

role-girl 是都市白裙卡牌；girl1 是針織窗景九格；character-turnaround-walk 偏動畫管道四視圖。艾琳娜線獨佔 original/game-girl/，避免文件名與敘事混用。以後若做「碧海群島」第二張角色，我會新開目錄，而不是把新臉硬塞進本頁 HTML。

維護約定

若我替換 ChatGPT-Image2.png 或改設定表佈局，會同步更新本文 JSON 的 dateModified，並在 changelog 寫一句。設定表版本號目前標 v1.0——對應 2025 頁腳年份是排版遺留，以文件夾內文件日期為準。

若你要複用這套結構

建議固定四件：一張寬構圖三視圖源、一份 HTML 設定表（信息 + 色板 + 世界觀）、按日期留探索 PNG、一篇說明「淘汰理由」的手記。比堆十篇「AI 工作流」更像有人在維護角色線，也方便 AdSense 審核員看出頁面主內容是站長寫的說明，而不是隻有外鏈或 RSS 標題。
