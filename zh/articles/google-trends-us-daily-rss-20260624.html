怎麼用（SEO 與日常）

  • 訂閱 RSS — 比手動刷 Trending 頁更省時間；本站在 JSON 裡保留新聞鏈接便於二次引用。
  • 點 Explore 鏈接 — 表格中趨勢詞鏈至 trends.google.com/trends/explore?geo=US&q=…，可看地區曲線與相關查詢。
  • 對照 CSV 存檔 — RSS 約 10 條/輪；Trending 導出可有數百條（見 6/22 文章）。大事件日用 CSV，日常脈衝用 RSS 即可。
  • 僅 US — 換 geo=GB、geo=JP 等需換 RSS URL。
  • 更新本站 — 運行 node tools/fetch-google-trends-rss.mjs → 編輯 JSON 日期若需 → npm run build-articles · npm run build-seo-locales。
