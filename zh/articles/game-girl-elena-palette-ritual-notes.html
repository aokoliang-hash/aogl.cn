艾琳娜配色與儀式 UI：HTML 設定表維護手記

色板硬字段 · 五表情佔位 · v1.0 維護約定

2026-06-18 · 本站原創

本文是 海島祭司艾琳娜 · 海風之詩 的續篇。首篇介紹 HTML 設定表、三視圖源圖與 5/18–5/20 探索圖；這裡寫我日常真正維護的內容：配色硬字段、五個表情佔位與設定表裡的「儀式 UI」語氣——仍是個人歸檔，不是商業遊戲 SKU。

為什麼另開 URL 而不改首篇

把配色規則塞進首發文會淹沒「角色色板」「HTML 設定表維護」等長尾。拆分後，首篇負責「是誰、有哪些文件」，本篇回答「改一個顏色怎樣不弄壞版式」。做法類似 WebGL 地球 與 真實行星貼圖 分兩頁。

左欄色板硬字段

主色（象牙白 / 天青 / 海藍 / 深海藍）、輔色（沙米 / 暖金）、強調色（杖金 / 冠綠 / 寶石藍）不是裝飾——是淘汰標準。新圖若頭髮偏霓虹紫、裙襬變大紅，在換 ChatGPT-Image2.png 之前直接棄用。色塊上的 hex 會抄進提示詞；我不從 PNG 自動吸色（曾有一次壓縮導致膚色漂移）。

五個表情圓：CSS 濾鏡佔位

每個情緒圈複用臉部裁剪 + filter:saturate/brightness/hue-rotate，是刻意的技術債：先讓版式可發佈，再補五張手繪表情。對外交付前必須換成真實裁剪——本站保留濾鏡是為了固定 UX 槽位（溫柔 / 微笑 / 沉思 / 堅定 / 喜悅），避免日後插圖到位時佈局跳動。

儀式 UI 文案

頁腳「Official Character Design · Confidential」營造 AAA 管線感，在本站僅表示版式語氣：無 NDA、無發行商、無 SKU。試玩者說有頁腳欄設定表更「像真的」——即便沒有保密協議。若開源 HTML，會在頁腳上加一句免責；目前海島幻想與假保密欄的反差也是 Demo 的一部分。

維護約定（v1.0）

  1. 更換 ChatGPT-Image2.png → 必須重查三視圖的 object-position。
  2. 改 hex 色板 → 更新文章 dateModified 與 changelog 一條。
  3. 加第六個表情 → 先改 HTML 網格，再畫圖——絕不反過來。
  4. 不在此頁嵌 WebGL / Live2D；動畫另開文章並寫清範圍。

配套工具書籤

出圖探索：Gemini、Midjourney 備忘。改表代碼：Cursor。模型政策提醒：快訊。這些鏈接不是背書，是我的目錄條目。

與遊戲 Hub 的關係

我在 games.html 掃第一方標題，再回到 original/game-girl/ 做個人美術實驗——流程見 遊戲 Hub × 生成式角色美術工作流。商店 RSS 不會自動改設定表；仍需人合併決策。

邊界

無骨骼、無引擎包、無抽卡數值、無配音選角。第三篇只會在新實物（例如手繪五表情）上線時出現，而不是為堆關鍵詞。

服裝 SVG 格：為何用內聯矢量佔位

設定表裡的服裝拆解用簡單內聯 SVG 剪影——不是最終服裝平面圖。它們存在的意義是：以後換 PNG 裁剪時，版面寬度仍穩定。每格標籤寫「主服 / 腰帶 / 頭飾 / 法杖」中文，因為維護時的第一讀者是我自己；英文文章向訪客解釋意圖。我拒絕把柵格服裝片嵌進 SVG 層；柵格只屬於三視圖條。

強調色硬淘汰規則

  • 杖金（#D4AF37） — 生成結果若偏橙銅，棄；法杖必須讀成金屬，不是木頭。
  • 冠綠（#2E8B57） — 只用於藤冠；絕不滲進頭髮高光。
  • 寶石藍（#4169E1） — 留給潮沙杖上的寶珠；不復用到瞳孔或唇彩。

5 月 19 日有一張探索圖把寶石藍塗到瞳孔上，我本地留作反例，但未放進首發文的公開圖庫。

表情濾鏡數值（佔位時代）

當前 CSS 在共享臉部裁剪上用輕度濾鏡：溫柔（亮度 +5%）、微笑（飽和 +10%）、沉思（亮度 −8%）、堅定（色相旋轉 5deg）、喜悅（飽和 +12%）。這些數字不是美學目標——只是在手繪圓盤到位前防止佈局跳動。寫在這裡，是為了換成真實 PNG 時能 diff。

換圖時的三視圖檢查清單

換 ChatGPT-Image2.png 後，我會按順序核：正面臉部中心是否仍落在 object-position 目標；側面耳線是否被裁切；背面發冠是否露出藤蔓。任何一處偏了，先改 CSS 裁剪，再考慮重出圖。設定表是維護面，不是「再生成一次就好」的藉口。

中文加厚：調色拒絕規則與設定表

elena_character_sheet.html 把調色、表情濾鏡與服裝格子放在同一頁，是為了避免「散圖文件夾」無法被審核員讀懂。金色點綴、冷綠陰影、群青輔色一旦同時搶戲，角色就會像貼紙而不是可落地的設定。我在手記裡寫拒絕規則，不是為了玄學，而是給未來的自己一份可執行的檢查表：換一版圖之前，先看色相是否破壞輪廓可讀性。
