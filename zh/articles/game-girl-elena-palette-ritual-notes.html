艾琳娜配色與儀式 UI：HTML 設定表維護手記

色板硬字段 · 五表情佔位 · v1.0 維護約定

2026-06-18 · 本站原創

本文是 海島祭司艾琳娜 · 海風之詩 的續篇。首篇介紹 HTML 設定表、三視圖源圖與 5/18–5/20 探索圖；這裡寫我日常真正維護的內容：配色硬字段、五個表情佔位與設定表裡的「儀式 UI」語氣——仍是個人歸檔，不是商業遊戲 SKU。

為什麼另開 URL 而不改首篇

把配色規則塞進首發文會淹沒「角色色板」「HTML 設定表維護」等長尾。拆分後，首篇負責「是誰、有哪些文件」，本篇回答「改一個顏色怎樣不弄壞版式」。做法類似 WebGL 地球 與 真實行星貼圖 分兩頁。

左欄色板硬字段

主色（象牙白 / 天青 / 海藍 / 深海藍）、輔色（沙米 / 暖金）、強調色（杖金 / 冠綠 / 寶石藍）不是裝飾——是淘汰標準。新圖若頭髮偏霓虹紫、裙襬變大紅，在換 ChatGPT-Image2.png 之前直接棄用。色塊上的 hex 會抄進提示詞；我不從 PNG 自動吸色（曾有一次壓縮導致膚色漂移）。

五個表情圓：CSS 濾鏡佔位

每個情緒圈複用臉部裁剪 + filter，是刻意的技術債：先讓版式可發佈，再補五張手繪表情。對外交付前必須換成真實裁剪——本站保留濾鏡是為了固定 UX 槽位（溫柔 / 微笑 / 沉思 / 堅定 / 喜悅），避免日後插圖到位時佈局跳動。

儀式 UI 文案

頁腳「Official Character Design · Confidential」營造 AAA 管線感，在本站僅表示版式語氣：無 NDA、無發行商、無 SKU。若開源 HTML，會在頁腳上加一句免責；目前海島幻想與假保密欄的反差也是 Demo 的一部分。

維護約定（v1.0）

  1. 更換 ChatGPT-Image2.png → 必須重查三視圖的 object-position。
  2. 改 hex 色板 → 更新文章 dateModified 與 changelog 一條。
  3. 加第六個表情 → 先改 HTML 網格，再畫圖。
  4. 不在此頁嵌 WebGL / Live2D；動畫另開文章並寫清範圍。

配套工具書籤

出圖探索：Gemini、Midjourney 備忘。改表代碼：Cursor。模型政策：快訊。

與遊戲 Hub 的關係

我在 games.html 掃第一方標題，再回到 original/game-girl/ 做個人美術實驗——流程見 遊戲 Hub × 生成式角色美術工作流。商店 RSS 不會自動改設定表。

邊界

無骨骼、無引擎包、無抽卡數值。第三篇只會在新實物（例如手繪五表情）上線時出現，而不是為堆關鍵詞。
