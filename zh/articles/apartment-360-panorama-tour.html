公寓 360° 全景漫遊：四房間熱點跳轉與 Three.js 內景球

Living-room · dining · kitchen · master-bedroom · panorama-viewer.html

2026-05-21 · 本站原創

這篇是 aogl.cn 歸檔的第 9 篇原創手記，素材在 original/360-degree-panorama/。我做的是一套可嵌入的公寓內景 360° 漫遊：四張 2:1 等距柱狀全景圖、一個 panorama-viewer.html 頁面，用 Three.js 把貼圖鋪在「內翻」球面上，再用熱點在客廳、餐廳、廚房、主臥之間跳轉。不是房產中介落地頁，也不教你怎麼買某款 SaaS；只記我這次 Demo 的結構和取捨。

文件夾裡有什麼

  • Living-room.png — 北歐風客廳，落地窗對公園
  • dining-room.png — 法式餐廳，水晶吊燈與長桌
  • kitchen.png — 島臺廚房，大理石臺面與銅鍋陳列
  • master-bedroom.png — 主臥，城市天際線落地窗
  • panorama-viewer.html — 可全屏操作的漫遊殼頁

四張圖都是完整一圈的室內全景：寬高比約 2:1，適合直接當 equirectangular 貼圖。若比例不對，球體接縫會有一條豎線或天空/地面被拉扁——我導出前會先看一眼左右邊緣能否無縫銜接。

為什麼用內翻球體而不是「普通」球

Three.js 裡常見寫法是 SphereGeometry 再 scale(-1, 1, 1)，把相機放在球心，人看向內壁。外表面貼圖時，你從外面看會像在看一顆行星；內景漫遊必須「站在房間中間轉頭」。相機幾乎固定在原點，lookAt 根據 yaw / pitch 轉；拖拽改的是觀察方向，不是繞物體公轉。

這和本站 交互 3D 地球 同屬 WebGL 球體，但地球是外觀測、帶光照與大氣；全景漫遊只要 MeshBasicMaterial 貼一張圖，省算力，也避免室內全景被平行光「洗平」細節。

四場景與熱點：我怎麼定義跳轉

panorama-viewer.html 頂部用 SCENES 數組配置場景。每個場景有 id、中文名、描述、image 文件名、初始 initYaw / initPitch，以及 hotspots 列表。

熱點分四類（頁面上顏色不同）：

  • entry — 進入另一個房間（例如客廳裡「前往餐廳」）
  • exit — 返回上一個空間
  • info — 彈窗說明（落地窗、吊燈、城市景觀等）
  • poi — 軟裝或物件興趣點（沙發、島臺、衣帽間）

每個熱點存 yaw、pitch（度），以及 targetScene 或 info 文案。屏幕上的圓鈕位置由當前相機方向投影到 2D 算出來；背對觀眾的熱點會隱藏，避免滿屏按鈕。

在線試玩（嵌入）

拖拽旋轉、滾輪改 FOV、雙擊重置；左側場景卡片可點；底部可上一景/下一景、開關自動輪播與緩慢自轉。手機端支持單指拖、雙指縮放。

四張全景靜幀（對照用）

若嵌入頁加載慢，仍可先看單張圖理解每個空間的構圖。文件名與場景 id 一一對應。

界面裡還有哪些值得寫進文章

頂欄顯示當前場景名；左側可摺疊「漫遊導航」用四張 16:9 縮略圖切換。右下角羅盤指針隨 yaw 旋轉，和拖拽方向一致。底部顯示 FOV 角度、上一景/下一景，以及自動輪播（默認約 9 秒）和慢速自轉。鍵盤方向鍵可微調視角，+ / - 縮放，r 回到該場景的初始 yaw/pitch。貼圖加載失敗時會用帶房間名的漸變畫布佔位，方便本地調試熱點位置。

過渡、加載與「假數據」邊界

切換場景時有黑色淡入淡出，避免貼圖還沒換完就露餡。首屏有加載條——四張圖從同目錄相對路徑加載，部署時要保證 PNG 與 HTML 同路徑關係不變。

熱點裡的文案（胡桃木餐桌、紅酒櫃、埃及長絨棉床品等）是配合畫面寫的示意說明，不是真實樓盤資料。若你 fork 去做真實房源，應整段替換 SCENES 與彈窗文字，並換上自己的測繪全景。

和本站其他 Demo 的關係

穿越視差手機 是分層 2D 視差；3D 地球 是外觀測球體加光照。本篇是室內 equirectangular + 多場景圖切換，更接近虛擬樣板間技術驗證。三條線並列放在首頁輪播，避免混成「一個地球裡有一套公寓」這種誤解。

若你要複用這套殼

  1. 每張全景保持 2:1（常見 4096×2048 或 2048×1024），左右邊緣對齊。
  2. 在 SCENES 裡增刪房間，熱點 yaw/pitch 在瀏覽器裡試調——我習慣先放一個 info 熱點對位置，再複製改 targetScene。
  3. 文章頁用 iframe 嵌入 + 上文說明，利於搜索理解「360 全景 / virtual tour / Three.js」。

我不在這裡列「十大全景插件」對比表：插件換得快，把你自己的場景圖 + 熱點邏輯寫清楚，比堆外鏈更有維護價值。
