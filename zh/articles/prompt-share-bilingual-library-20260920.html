Prompt Share：中英雙語多任務提示詞庫手記

本人開發 · App：http://prompt.aogl.cn/ · 文圖視頻 · 合集 · 提交審核

2026-09-20 · 本站原創

這是 aogl.cn 上的本人一手產品手記。截圖歸檔在 original/prompt-share/（2026-09-20）。Prompt Share 是我自己開發的應用（頁腳 © 2026 Prompt Share · 提示詞分享）。入口：http://prompt.aogl.cn/——面向文本、圖像、視頻、音頻工作流的中英雙語多任務提示詞庫。卡片打開類似 Midjourney 的右側抽屜，可一鍵複製中英文提示詞；合集打包入門樣例；任何人可無註冊提交，經管理員審核後公開。本文不是聯盟軟文，而是對照本人 UI 截圖寫清：首頁篩選、抽屜詳情、提交表單、合集索引，方便檢索「雙語提示詞庫」「文生視頻提示詞分享」「可靈 / Midjourney 中英提示詞」「prompt.aogl.cn」等意圖。

定位：跨模態的一座庫

多數「提示詞站」要麼是純英文 Midjourney 瀑布流，要麼是中文聊天片段貼進博客。Prompt Share 的契約不同：按輸出模態與生成任務建目錄，中英提示詞正文是一等公民字段。首頁標語寫得很直白——多任務提示詞庫 · 中英雙語 · 文圖視頻一站收藏。導航很短：提示詞、合集、提交、管理。產品是「庫 + 投稿隊列」，不是社交動態牆。

放在子域 prompt.aogl.cn，與 WordPet、EatToday、世界之最同一套路：交互產品在子域；製作手記與 SEO 長文留在 aogl.cn 首屏 HTML。

篩選：按人們真正生成的方式切

搜索框下方兩行芯片：

  • 輸出類型 — 全部、文本、圖像、視頻、音頻（?output_type=）。
  • 任務類型 — 文→文 (t2t)、文→圖 (t2i)、圖→圖 (i2i)、多圖→圖 (r2i)、文→視頻 (t2v)、圖→視頻 (i2v)，以及「更多」裡的多參→視頻、視頻→視頻、文→音頻、語音→文、圖→文、混合；另有「精選」。

搜索佔位「搜索標題、摘要或提示詞…」把標題、摘要與提示詞正文一併檢索。合集是獨立打包（首頁「精選起步」→ /collection/getting-started；總覽 /collections）。首頁樣例標題包括：城市夜景航拍運鏡、電影感人像光影、品牌文案助手、靜物轉微距運鏡、多參考服裝平鋪、產品圖風格統一——覆蓋運鏡、人像光影、文案與電商出圖。

詳情抽屜：中英複製，參數不丟

點卡片打開右側抽屜（類似 Midjourney，不必整頁跳轉）。夜景航拍樣例可見任務「文→視頻」、模型「可靈」、一行摘要，然後：

  • 中文提示詞 + 複製 — 例如：城市夜景航拍，霓虹倒影，緩慢向前推進，電影級穩定運鏡，細雨溼路面。
  • English prompt + Copy — Aerial night cityscape, neon reflections, slow forward push-in…
  • 若有負面提示則單獨一塊。
  • 膠囊/標籤：fps 24、camera slow push-in、resolution 1080p、duration_sec 5、可靈、電影感等。

「完整頁」用於需要可分享 URL 時打開獨立頁。核心循環是：瀏覽 → 看雙語正文 → 複製 → 貼進可靈 / Midjourney / GPT 類工具。參數做成結構化膠囊，避免「24fps / 5 秒 / 緩推」淹沒在長段落裡。

合集：專題打包，而不是無限滾動

/collections 標題為「合集」，副標題「專題打包的提示詞精選」。首個包「精選起步」標註「雙語樣例合集」。合集服務入門：新訪客不該面對只有篩選、沒有指引的空牆。對審核員而言，人工打包路徑也比空洞網格更像「作者在策展」。

無註冊提交，審核後公開

/submit 寫明：無需註冊。提交後進入審核，通過後才會公開顯示。表單收集：

  1. 任務類型（t2t…mixed）、必填標題、可選英文標題、摘要、模型/工具（示例 GPT-4o、Midjourney、可靈）。
  2. 分類（寫作 / 圖像 / 視頻 / 工具）、默認展示語言、僅管理員可見的聯繫方式。
  3. 標籤最多 8 個：GPT、Midjourney、人像、可靈、電商、電影感等。
  4. 中文提示詞 + English prompt（至少一側）、可選系統提示與負面提示、Markdown 說明、參數 JSON、授權說明、封面與效果素材。
  5. 提交審核 — 有頻率限制；前臺僅展示已通過條目。

取捨很明確：投稿零註冊摩擦，首頁不被垃圾刷屏。表單含「公司網址」蜜罐字段；管理入口在 /admin/login。

為何子域 + 本站歸檔

時間戳截圖放進 original/prompt-share/ 便於追溯。封面走 npm run generate-article-covers 生成 Open Graph WebP。中文服務「提示詞庫 / 文生視頻 / 可靈提示詞」；英文服務 bilingual prompt library / text-to-video / Kling Midjourney share。短語言包故意短——過審重量在中英厚文。

相對本站榜單存檔（noindex），Prompt Share 屬於可索引主文：原創產品、原創截圖、第一人稱過程，與 WordPet、EatToday 同類。

寫作時不願稀釋的約束

  1. UI 文案照抄：Prompt Share、合集、提交審核、文→視頻、精選起步。
  2. 不聲稱提示詞為廠商官方；它們是面向可靈、Midjourney 等工具的社區/編輯配方。
  3. 外鏈優先寫 http://prompt.aogl.cn/，直至 HTTPS 穩定。
  4. 卡片數量會隨審核變化；本文凍結 2026-09-20 截圖集。
  5. 「無需註冊」≠「立刻公開」；必須過審。

無障礙與 SEO 清單

  • alt 寫清篩選、抽屜標題與表單分區，禁止「圖片 1」。
  • 正文重複：Prompt Share、http://prompt.aogl.cn/、雙語、t2i/t2v、合集、提交審核、可靈、Midjourney。
  • 產品外鏈 rel="noopener noreferrer"；完整敘事在首屏 HTML。

邊界

這些截圖記錄的是本人開發的 Prompt Share——個人產品與 UI 歸檔。提示詞正文、標籤與合集成員會隨時間變化。本文不聲稱與 OpenAI、Midjourney 或可靈存在官方合作。生成內容如何使用，由使用者自行負責。
