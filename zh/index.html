關於本站

aogl.cn 是個人維護的生成式 AI 備忘站：聚合官網博文與文檔入口，方便自己查閱，也歡迎路過收藏。所列外鏈均在新標籤頁打開；正文多為摘錄或短評，不是商業評測機構，定價、地區策略與條款請以各公司頁面為準。

下方「內容板塊」對應頁內 RSS 分類；「工具分類導航」按場景手工整理常見產品官網（對話、生圖、視頻、代碼等），省得翻收藏夾。若鏈接失效、名稱變更或希望撤下某站，可在倉庫發 GitHub Issue 說明，有餘力時會改。

本站不當新聞站用：長文若寫會單獨開坑；列表與短訊會盡量標註時間與出處，便於日後核對。聯繫維護者（郵箱、GitHub 等）見 聯繫我們。
