Gemini

对话与大模型

说明：本页为 aogl.cn 书签站整理的工具简介，非厂商官方文档；功能与价格以官网为准。

Gemini 是我常用的 Google 对话入口，主要做快速出图找感觉和在进 data/articles/ 前头脑风暴文案。与 Claude 并列在工具目录，因为文本聊天重叠，但多模态默认和 Google 账户体系不同。

在本站的用法

  • 头图探索 — original/role-girl/、original/character/ 等目录下的 PNG（水印仅作来源说明，不在此教去除）。
  • 配色核对 — 问「同一套衣服吗」再定稿 contact sheet。
  • 标题备选 — changelog 用，三选一后手改。

实际流程

  1. 从下方按钮进 gemini.google.com，用愿意做实验的 Google 账户。
  2. 写清约束：画幅、服装锚点、不要 logo。
  3. 下载到 original/项目名/ 并带日期命名；不覆盖线上 Demo 主文件。
  4. 文章里如实写哪些进成片、哪些留在 look-dev。
  5. API / Vertex 细节请读 Google 开发者文档，不以本页代替。

和 Claude 的分工

长英文改写、细读代码多用 Claude；快速视觉和 Google 生态问题多用 Gemini。书签里两个都保留，不假装一个标签万能。

本站上的官方动态

DeepMind 发模型文时，同步摘要可能在 快讯，外链阅读原文，不能替代发布说明。

不要用来…

  • 把生成图说成官方品牌素材。
  • 无人审核批量发文（与本站维护方式不符）。
  • 代替持证专业人士做判断。
