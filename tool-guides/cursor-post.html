Cursor

编程与 IDE

说明：本页为 aogl.cn 书签站整理的工具简介，非厂商官方文档；功能与价格以官网为准。

Cursor 是我维护本静态仓库用的 IDE：多语言 HTML、Node 构建脚本和 data/ 下的 JSON。放在工具目录的「编程与 IDE」里，因为改动最终要进 git——不是看新闻的地方。

在 aogl.cn 上的常见任务

  • 重构构建脚本（如 build-seo-locale-pages.mjs、hub 生成器）并保留仓库上下文。
  • 生成多语言 HTML 壳，再手改 lang-* 块。
  • 集中导航前全局搜索所有 site-nav 副本。
  • 在集成终端跑 npm run build-site 并逐文件修 lint。

怎样不让 Agent 改坏站

  1. 缩小范围 — 一次一个脚本或一个 hub JSON，不顺手格式化无关 HTML。
  2. 必跑构建 — build-hubs / build-articles 失败则任务未完成。
  3. 不贴密钥 — 公开脚本里的 AdSense ID 可以，私有 token 不行。
  4. 保留标记 — INDEX_ORIGINALS_AUTO_START 等注释区间不能被覆盖。

和 GitHub Copilot 的分工

目录里两者都有。跨文件重构、以工作区为上下文的对话用 Cursor；单文件内补全用 Copilot 更轻。按任务粒度选，不站队。

局限

  • 不能代替阅读 Claude、Gemini 或 API 定价的官网文档。
  • 不会替我跑 GitHub Actions 定时任务。
  • 对外文章里的生成文案发布前仍要人工核对事实与语气。
