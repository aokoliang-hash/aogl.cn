我把 Claude 放在首页工具目录对话类前排，是因为写长文修订、静态站改动二审时常用它——不是因为每条榜单都排第一。本页记录的是我在 aogl.cn 的书签用法，不是商业评测。

我什么时候开 Claude

  • 长文档 — 贴 hub JSON 或文章片段，先要结构意见再改 HTML。
  • 语气保留的改写 — 英文 description、changelog 句子，要完整句而不是堆关键词。
  • 读代码 — 让陌生构建脚本用白话解释；实现仍以仓库为准。

多文件仓库内改代码我会换 Cursor；要快速出文章头图类多模态草稿会用 Gemini。

五步备忘流程

  1. 从本页进官方 claude.ai（不用来路不明的镜像）。
  2. 确认模型选择与账户档位和官网一致。
  3. 只贴非机密片段——不含 API 密钥或客户隐私。
  4. 有用结论手抄进 data/articles/fragments/ 或 changelog。
  5. 大版本发布先看 Anthropic 原文；同步后可在本站 快讯索引 找到摘要链。
