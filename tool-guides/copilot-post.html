Copilot 是我在 Edge / Windows 里想快速要一个带网页语境的答案时开的入口，不必先开完整 Claude 会话。见首页工具目录；非微软背书。

维护本站时何时用

  • 改构建脚本前先概括长篇微软 / GitHub 文档。
  • 本地 WAMP 测试时查 Windows / API 变更。
  • 起草 changelog 短句再进 git 手改。

全仓库重构用 Cursor；要引用来源用 Perplexity。

五步流程

  1. 从下方按钮进 copilot.microsoft.com。
  2. 确认登录的是预期微软账户。
  3. 只贴非机密片段。
  4. 有用结论抄进自己的笔记，不自动发站。
  5. 价格与地区以微软官网为准；本页核对 2026-06-18。
